# 마롱이 얼굴 그림

통화 홈과 통화 중 화면에 보이는 마롱이 얼굴 그림이에요(TERM-018). 동희님이 2026-11-12 14:21(한국 시각)에 올린 표정 그림 19장(1024×1024 투명 PNG)과 그 그림을 만든 지시문, 15:02에 올린 GPT GIF 3개에서 왔어요. 언제 어떤 얼굴을 쓰는지의 원본은 [기능 명세 3.5 '얼굴 규칙'](../../docs/04-functional-spec/spec.md)(SPEC-029, SPEC-030)이고, 이 문서는 그림 번호·파일·만드는 법만 적어요.

어디에 둘지는 동희님이 2026-11-12 14:48(한국 시각) 결정 카드에서 '화면용 그림만 넣기'를 골라 정했어요(Notion '결정할 것' D14). GIF도 같은 방식으로 원본은 Git 밖에 두고, GIF에만 있던 입·눈 조합 4장(20\~23번)만 화면용으로 넣었어요. 원본이 필요하면 프로젝트 파일의 zip에서 꺼내요.

통화 서버는 `/static/face/v1/`을 `Cache-Control: public, max-age=31536000, immutable`로 내줘요. 그림을 바꾸면 폴더를 `v2`로 바꿔요. 서비스 워커는 그림을 캐시하지 않아요(SPEC-027, SPEC-029).

## 말하는 움직임(talk)

동희님이 2026-11-12 15:05(한국 시각) 프로젝트 채팅에서 "talk는 지피티에서 만들어온게 좋은듯"이라고 하셔서(D15), 마롱이가 말할 때 입은 소리 크기를 따르지 않고 GPT talk GIF `marongi-speaking.gif`의 칸 순서와 시간을 그대로 따라요. 표는 [기능 명세 3.5 표 4·5](../../docs/04-functional-spec/spec.md)에 있어요.

- 한 바퀴는 13칸 1.98초예요: 01 0.21초 → 15 0.09초 → 16 0.17초 → 15 0.10초 → 01 0.12초 → 15 0.08초 → 16 0.12초 → 15 0.13초 → 01 0.23초 → 15 0.11초 → 16 0.23초 → 15 0.13초 → 01 0.26초.
- 마롱이 소리가 시작되면 2번 칸(15)부터 돌고, 0.3초 동안 소리가 없으면 바로 01로 돌아가요.
- 깜빡임은 talk와 따로 3\~6초마다 와요. 깜빡이는 동안 입 칸은 그대로 가고 눈만 바꿔요(입 닫음 18·19, 입 조금 20·21, 입 크게 22·23).
- 감정 얼굴(02\~13)에는 입 칸이 없어서, 말하는 동안 talk 칸에 맞춰 위로 튀기만 해요(01 0px, 15 2px, 16 4px).
- 움직임 줄이기를 켜면 talk·깜빡임·튀기를 멈추고, 말하는 동안은 15로 멈춰 둬요.

GIF 파일을 화면에 그대로 띄우지 않는 이유(Claude 판단):

- 화면 코드가 GIF를 멈추거나 처음부터 다시 틀 수 없어요. 말이 멈춰도 입이 돌거나, 다음 말이 아무 칸에서나 시작해요.
- 깜빡임이 늘 같은 자리에 와요(깜빡임 GIF는 3초마다). 따로 돌리면 3\~6초 사이 무작위로 깜빡일 수 있어요.
- GIF는 투명이 켬·끔뿐이에요. 01번 테두리의 반투명 화소 4,551개가 GIF에서는 1,763개 켬, 2,788개 끔으로 바뀌었어요. WebP는 반투명을 그대로 가져요.
- 감정 얼굴의 튀기, 움직임 줄이기와 섞을 수 없어요.

그래서 같은 칸을 WebP로 두고 GIF의 순서와 시간을 화면 코드가 따라요. 보이는 움직임은 GIF와 같아요.

## 그림이 맞춰진 방식

올린 파일을 읽어서 잰 값이에요(2026-11-12).

- PNG 19장 모두 1024×1024 RGBA이고 네 귀퉁이가 투명해요.
- 몸 상자는 모든 그림에서 x 205\~819, y 239\~785로 같아요. 그래서 칸을 바꿔 끼워도 몸이 흔들리지 않아요.
- 14번과 17번은 01번과 바이트까지 같아요.
- 15·16번은 01번에서 입 부분(x 462\~551, y 459\~544)만, 18·19번은 눈 부분(x 413\~600, y 430\~472)만 보이게 달라요. 아주 작은 차이까지 치면 입은 x 456\~556·y 453\~545, 눈은 x 413\~601·y 424\~476이고, 둘이 겹치는 화소는 9\~12개뿐이에요. 그래서 입·눈 칸은 기본 얼굴(01)에만 맞아요.
- GIF 3개는 모두 1024×1024, 팔레트 색(첫 칸 103색), 끝없이 되풀이예요. 투명은 PNG 알파 128 이상을 켬으로 나눈 것과 똑같아서, 몸 상자가 x 207\~816·y 241\~783으로 2화소쯤 작아요.
- GIF의 칸은 PNG 01·15·16·18·19와 같은 그림이에요(불투명한 곳의 색 차이 평균 1.4, 팔레트 때문).
- 깜빡임 GIF `marongi-blinking.gif`: 01 1.24초 → 18 0.05초 → 19 0.07초 → 18 0.06초 → 01 1.58초(5칸 3초).
- talk와 깜빡임 GIF `marongi-speaking-and-blinking.gif`: 44칸 5.94초. talk 사이에 눈만 0.05·0.07·0.06초로 감고 뜨는 동안 입은 계속 움직여요. 이때 쓰는 입·눈 조합 칸 4개가 20\~23번이에요.

## 화면용 그림 만들기

- 원본을 RGBA로 열어 Lanczos로 512×512로 줄이고, 무손실 WebP(`lossless=True, quality=100, method=6`)로 저장해요. 알파는 그대로예요. 같은 방법으로 01번을 다시 만들면 저장소의 `01-neutral.webp`와 바이트까지 같아요(Pillow 12.3.0).
- 파일 이름은 원본 이름에서 `marongi-`를 빼고 확장자를 `.webp`로 바꿔요. 14·17번은 만들지 않아요.
- 20\~23번: 01번에 18·19번의 눈 화소(01번과 다른 화소)를 얹고, 그 위에 15·16번의 입 화소를 얹어 1024 그림을 만든 뒤 위와 같이 줄여요. 이렇게 만든 1024 그림은 GIF 칸과 색 차이 평균 1.43\~1.44(팔레트 때문)이고 투명 경계는 모두 같아요.
- 화면은 248px(통화 중), 200px(홈), 152px(끝난 화면)로 그려요(토큰 `size.face-*`). 기기 화소 비율이 3인 화면에서 248px 상자는 744화소라서 512px 그림을 키워 그려요. 흐려 보이는지 실기기에서 보고, 흐리면 더 큰 판으로 다시 만들어요(파일이 커져요, 기능 명세 7.2 14번).

## 새 얼굴을 더할 때

- 01번을 편집 기준으로 같은 1024 캔버스와 같은 몸 상자를 지켜요. 원본 지시문의 공통 부분을 그대로 써요.
- 감정 얼굴에도 입을 움직이고 싶으면 그 감정마다 입 그림 두 장(조금·크게)을 더 만들어야 해요. 말하며 깜빡이게 하려면 그 감정의 입·눈 조합도 더 필요해요.
- 그림을 더하거나 바꾸면 `v2` 폴더로 옮기고 기능 명세 3.5의 표를 같은 변경에서 고쳐요.

## 확인하지 못한 것

- 갤럭시 Chrome에서 원격 WebRTC 소리를 `AnalyserNode`로 잴 수 있는지(못 재면 자막 조각이 오는 동안을 말하는 중으로 보고 같은 talk 움직임을 보여요).
- talk 움직임이 마롱이 목소리와 어색하지 않은지(입은 소리 크기를 따르지 않아요).
- 248px에서의 선명함과 LTE에서 21장을 미리 받는 시간.
