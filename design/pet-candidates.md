# 반려동물 서비스 목업 후보(09단계)

2026-11-17 설계(Claude). 지금 상태: 반려동물 서비스(SCR-140\~162) 중 네 화면을 두 안씩 그렸어요. 09 단계 규칙대로 방향을 하나 고른 뒤에 나머지 상태를 그 안으로 그려요. 방향은 동희님이 골라요(아래 '결정').

- 공통 캔버스: [마롱이 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9) 버전 18의 '반려동물' A줄·B줄(대지 10장). 이름은 `C022-<A|B>-<SCR>-<상태>-<테마>`이고, 방향이 정해지면 고르지 않은 줄은 맨 아래 비교 칸으로 옮겨요.
- 프로젝트 파일 `marong-pet-mockup-20261117/`: `compare-A-B.png`(다섯 대지의 첫 화면을 A 위·B 아래로 한 장에, 먼저 이것만 보면 돼요), `png/`(대지 10장 전체 길이, 2배 해상도), `mock.html`(같은 대지를 한 페이지에), `wireframes-pet.html`(08 와이어프레임 사본).
- 화면 정의(08단계): [pet.md](../docs/08-screens/pet.md), 와이어프레임 [wireframes-pet.html](../docs/08-screens/wireframes-pet.html)(상태 220개 × 360·430px). 목업과 정의가 다르면 정의가 맞아요.

## 그린 방법

- HTML 대지를 Chromium(Playwright)에서 글꼴을 불러온 뒤 찍었어요. 글꼴: Noto Sans KR(본문), Gaegu(A의 일기 손글씨, `font.diary`), Gowun Dodum(B의 제목, 이미 있는 `font.display-b`).
- A는 화면 공통 기준([README.md](README.md) 1\~4절, [base.tokens.json](base.tokens.json))의 토큰 값만 썼어요. B는 아래 '후보 B 토큰'의 새 색 두 벌을 썼고 크기·간격은 공통 토큰 그대로예요.
- 개·고양이·방·공원 그림은 그림 모델이 그릴 그림의 자리 그림(placeholder)이에요. UI 토큰이 아니에요.
- 예시 글(콩이, 보리, 산책, 비둘기)과 값(한도 60%, 5,900원, 12월 17일)은 화면을 보이려고 지은 것이에요. 실제 사용자나 친구의 대화가 아니에요. 가격 원본은 06 API와 04 명세예요.

## 추천

**A(마롱이 앱 모양 그대로).**

- 새 토큰이 없어서 토큰 얼리기를 한 번에 끝낼 수 있고, GPT가 이미 있는 CSS 변수와 일기 부품을 다시 써요.
- 반려동물 일기가 마롱이 일기(SCR-113)와 같은 종이 모양이라, 일기 부품을 한 번 만들어 두 서비스가 같이 써요.
- 공통 기준 2절 "새 화면은 앱 모양이 기본이에요"와 맞아요.
- 반론: 반려동물 서비스는 마롱이를 모르는 사람에게 파는 공개 유료 서비스(CTX-022\~025)라, B처럼 반려동물 앱다운 첫인상과 시스템 어두움 모드가 더 맞을 수 있어요. 그 점만 가져오려면 A를 고르고 홈(SCR-140)의 카드만 B처럼 그림을 크게 하는 방법이 있어요(새 토큰 없이 배치만 바뀜). 시각 기준 테마 대신 시스템 설정을 따를지는 따로 정할 수 있는데, 그러면 공통 기준 1절과 갈라져요.

## 후보 B 토큰(B를 고를 때만 넣어요)

B를 고르면 `base.tokens.json`에 `color.p`(밝음)·`color.q`(어두움)으로 넣고, 반려동물 화면만 시스템 설정으로 둘 중 하나를 써요. A를 고르면 넣지 않아요.

## 확인한 것과 못 한 것

- 확인함(2026-11-17, Playwright로 `mock.html`을 띄워 잼): 대지 10장 모두 360px 폭에서 가로로 넘치는 요소 0개, 누르는 곳(버튼, 글 버튼, 아이콘 버튼, 보내기, 아래 탭) 모두 높이 44px 이상, 글꼴 세 개를 불러온 뒤 찍음.
- A의 대비는 이미 있는 토큰이라 [persona-candidates.md](persona-candidates.md)·[diary-candidates.md](diary-candidates.md)의 표와 같아요(모두 4.5:1 이상).
- 확인하지 않음: 430px 목업(와이어프레임으로만 봄), 1280px 홈의 색, 화면 읽기 프로그램, 움직임, 실제 휴대폰, 그림 모델이 실제로 그린 그림을 넣은 모습. 11\~12 단계에서 실제 화면으로 재요.
