# 통합 앱(MVP) 목업(09단계)

2026-11-19 설계(Claude). 지금 상태: 통합 앱 화면(SCR-163\~174)과 바뀌는 화면 둘(SCR-107, SCR-002)을 대지 17장으로 그렸어요. 동희님이 2026-11-19 13시대 KST 설계 스레드에서 "목업 보여조"라고 하셔서 그렸고, 14:13 KST에 그린 방향 그대로 가기로 하셨어요(D105, 아래 '결정').

- 캔버스: [마롱이 통합 앱 목업](https://claude.ai/artifact/GXVep4QepAUdFhH6gDmLb3)(비공개, 공유받은 사람만). 공통 캔버스 '마롱이 화면 설계'는 이 스레드가 열 수 없는 계정의 것이라 캔버스를 따로 만들었어요.
- 화면 정의(08단계): [unified.md](../docs/08-screens/unified.md). 목업과 정의가 다르면 정의가 맞아요.
- 부품 스타일: [unified-mockup.css](unified-mockup.css). 대지가 같이 쓰는 클래스 한 벌이고, 모든 값이 [base.tokens.json](base.tokens.json)의 얼려 둔 토큰이에요(D67). 변수 이름은 [README.md](README.md) 3절을 따라요.

## 방향

후보를 둘 그리지 않았어요. 방향은 이미 정해져 있어요: 앱 모양은 지금 글 대화·통화 화면 그대로이고, 캐릭터 만들기는 반려동물 A안(D72)의 부품을 써요. 새 토큰은 없어요.

## 그린 방법

- 대지는 실제 HTML이에요(그림이 아니에요). 버튼·입력 칸·스위치가 진짜 요소이고, 색·크기·간격은 `unified-mockup.css`의 토큰 변수만 써요.
- 글꼴은 `font.body` 그대로예요(아이폰은 Apple SD Gothic Neo, 그 밖은 Noto Sans KR).
- 마롱이 얼굴은 저장소의 얼굴 그림(01)이에요. 강아지 그림은 그림 모델이 그릴 그림의 자리 그림이에요. 표정 여섯 장도 같은 자리 그림을 되풀이해 썼어요.
- 이름(지우, 콩이, 하늘, 민서, 도윤, 서아), 숫자, 친구 코드, 초대 주소(`marong.example`)는 화면을 보이려고 지은 것이에요. 실제 사용자나 친구의 것이 아니에요.

## 정의에 없는 글

목업을 그리면서 넣은 글이에요. 문구 원본은 화면 정의이고, 아래는 구현 때 정의에 맞추거나 정의에 더할 후보예요.

| 화면 | 넣은 글 | 성격 |
| --- | --- | --- |
| SCR-163, SCR-174 | 이름 칸의 이름표 '이름' | 칸 이름표(화면 읽기 프로그램용으로도 필요) |
| SCR-167 | 목소리 이름표 여덟 개(맑은 목소리 등) | 예시. 실제 목록은 듣기 시험 뒤에 정해져요 |
| SCR-168 | 요청 칸의 안내 글 '글자와 숫자 6자' | 칸 안내 글 |
| SCR-166 | 견본 말 세 줄, 통화 첫마디 '여보세요? 나 콩이야!' | API-227이 주는 값의 예시 |
| SCR-171 | 칸 이름표 '털 색 (1\~3개)', '말투 한 줄 (선택)' | 칸 이름표 |

## 확인한 것과 못 한 것

- 확인하지 않음: 대지를 띄워서 재지 않았어요. 줄바꿈, 넘침, 대지 높이, 누르는 곳의 실제 크기, 대비를 화면에서 보지 않았어요. 캔버스 형식의 안내가 만든 뒤 띄워 검사하지 않도록 정해 두어서, 동희님이 보시고 어긋난 곳을 알려 주시면 고쳐요.
- 값으로만 본 것: 누르는 곳은 모두 `size.touch-min`(48px) 이상의 클래스를 썼고(글 대화 머리 버튼은 지금 화면과 같은 44px), 색은 대비 표가 이미 있는 토큰이에요([persona-candidates.md](persona-candidates.md), [diary-candidates.md](diary-candidates.md)).
- 밤하늘의 입력 칸 테두리(`input-border`)는 토큰 값이 옅어요. 지금 글 대화 화면과 같은 값이에요.
