## 요구사항

우선순위: Must(없으면 내보내지 않음), Should(첫 버전에 넣음, 늦어지면 뒤로), Could(되면 좋음). 상태: active(2026-11-23 체크포인트 통과, D135), deferred(미룸, D138). 기능 변경 3의 REQ-586·587은 2026-11-24 체크포인트 통과(D147)로 active예요.
'관리 페이지'는 `/chat/admin/` 아래의 화면 그룹이에요(TERM-176, D136 1-1로 바뀜). 관리자는 동희님 한 사람이에요.

## 겹침·모순·열린 질문

- REQ-572와 REQ-579: 같은 숫자(통화 월 합, 그림 비용)를 개요는 요약으로, 비용 화면은 줄로 보여요. 개요는 API-280, 비용 화면은 API-280의 통화 칸과 API-266·236을 읽어요. 같은 때 읽으면 같은 값이에요.
- REQ-577과 REQ-575: 회원 한 사람 화면에서 '이 사람의 폰'을 보이려면 API-267의 폰을 회원에 맞춰야 해요. PR #101(커밋 `b54547d`)이 API-267에 `friendId`(회원 API와 같은 번호)를 더해서, 사람은 이 번호로만 맞춰요(SPEC-453, 기능 명세 3.5). 모순은 아니에요.
