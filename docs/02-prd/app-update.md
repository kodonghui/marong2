# 마롱이 앱 자동 업데이트: 요구사항

상태: 초안(2026-11-17 12시대 KST, Claude, corthex 0.12.1). 범위 동결 전이에요. 확인 질문 세 개(아래 '열린 질문', 01 단계 8절과 같음)는 D63(2026-11-17 15:15 KST) 결정 카드 '추천대로 모두 정하기'(9\~11번)로 추천안대로 정해졌어요.
입력: [도메인 설계](../01-domain/app-update.md)의 CTX-021과 TERM-092\~100, 앱 설계([docs/android-app.md](../android-app.md))의 REQ-110, 글 대화 설계([docs/app-chat.md](../app-chat.md))의 REQ-118과 SCR-109.
ID 번호: REQ는 306부터 써요(CTX-020의 다음 번호, 01 단계 머리말).

## 요구사항

우선순위: Must(없으면 내보내지 않음), Should(첫 버전에 넣음, 늦어지면 뒤로), Could(되면 좋음). 상태: active, proposed(확인 질문의 답 대기), deferred(이번 버전에서 뺌).

## 겹침·모순·열린 질문

- 겹침: REQ-316과 REQ-312는 둘 다 REQ-118에서 나왔어요. 앞은 앱이 보내는 것, 뒤는 서버가 남기는 것이라 둘 다 둬요.
- 모순 아님: REQ-110('같은 키로 서명한 직접 설치 APK')은 그대로예요. 자동 업데이트도 같은 키로 서명한 APK만 설치해요(REQ-317).
- 범위 밖: Play 스토어 배포(android-app.md '하지 않는 것', 결제가 들어서 동희님이 원할 때만), 바뀐 점 안내(확인 질문 3), 서버가 푸시로 새 버전을 알리기(앱이 푸시를 받을 때 확인하므로 따로 두지 않음).
- 0.2.1 → 0.2.2: 0.2.1에는 이 기능이 없어서 0.2.2는 손으로 한 번 깔아요(01 단계 4절). 그 뒤 버전부터 자동이에요.
- 열린 질문(01 단계 8절과 같아요. "추천대로" 또는 바꿀 번호만 말하면 돼요):
  1. 언제 설치할지(REQ-319): ① 통화·벨이 없고 앱 창이 화면에 없을 때만(추천) ② 받는 즉시
  2. 처음 허용 안내(REQ-325): ① 글 대화 메뉴에 '자동 업데이트' 줄과 '켜기' 단추 + 0.2.2 설치 안내에 한 줄(추천) ② 0.2.2를 처음 열 때 바로 설정 화면으로
  3. 설치 뒤 알림(REQ-324): ① 조용히 설치, 확인이 꼭 필요할 때만 알림(추천) ② '새 버전으로 바뀌었어요' 알림을 한 번
