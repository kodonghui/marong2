# 아이폰 홈 화면 웹앱 알림 02단계 버전 확정 후보

2026-11-25 KST · 마롱이 Orca 항목 143 · 02단계 범위 승인 · 버전 고정 대기

사용자님이 선택하신 사용 방식은 **“홈 화면 웹앱 알림을 눌러 받기”**입니다. 로그인한 아이폰 사용자가 홈 화면의 마롱이에 알림을 허용하면 새 답변·선톡·일정 알림을 받고 해당 글 대화로 이동합니다. 약속 전화 알림을 누르면 기존 웹 받기 화면으로 이동합니다. 알림을 연 뒤 사용자가 **받기**를 선택하고, 유효한 전화만 연결합니다.

## 범위와 근거

- **승인** — 사용자님 직접 결정은 2026-11-25 03:22:31 KST, Orca 항목 143 e2412입니다. 오랑이의 01단계 설계 위임 답변은 `msg_b4adaa0fa8ec`이며, 질문 `msg_5cbb3ebecdca`의 추천안 1~6을 승인했습니다. 아래 근거 열의 **위임 1~6**은 그 답변의 각 번호입니다. 02단계에서는 오랑이가 요청 `msg_822cfaeef194`에 답변 `msg_ff93c629ac92`로 만료 전화(A), 보고 있는 답변 푸시(B), REQ-640~675의 범위(C)를 승인했습니다. 행 상태 `proposed`는 범위 승인을 반영한 이 버전의 고정 체크포인트가 남았음을 뜻합니다.
- **확인된 사실** — Android와 아이폰은 글 대화와 통화 서버를 공유합니다. 아이폰용 홈 화면 manifest는 배포돼 있습니다. 현행 웹은 방에 남은 글과 유효한 약속 전화의 받기 버튼을 제공하며, 마롱이의 웹 푸시 구독·전송 구현은 없습니다. ### 알림을 눌렀을 때의 결과

글 알림은 해당 계정의 방에 남은 메시지로 이어집니다. 전화 알림은 통화 상태를 확인한 뒤 기존 받기 화면이나 유효하지 않은 상태로 이어집니다. 점선은 알림 전달, 실선은 사용자 동작 또는 서버 확인입니다.

```mermaid
%% grammar: structure
flowchart LR
    chat["CTX-001<br/>방의 메시지"]
    ring["CTX-020<br/>약속 전화"]
    push["홈 화면<br/>웹 알림"]
    tap["알림 탭"]
    guard["CTX-026<br/>계정 확인"]
    room["CTX-001<br/>글 대화"]
    call["CTX-002<br/>전화 상태 확인"]
    answer["기존 받기"]
    ended["만료·이미 받음"]
    chat -.-> push
    ring -.-> push
    push --> tap
    tap --> guard
    guard --> room
    guard --> call
    call -->|유효| answer
    call -->|종료 상태| ended
```

## 독립 목록으로 점검한 범위

Apple의 [홈 화면 설치](https://support.apple.com/en-az/guide/iphone/iphea86e5236/26/ios/26), [잠금 화면·집중 모드·알림 설정](https://support.apple.com/en-bh/guide/iphone/iph7c3d96bab/ios), WebKit의 [권한 요청과 다중 설치](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)를 제품 요구사항과 대조했습니다. Apple·WebKit이 보장하는 기능과 마롱이의 실기기 검증은 따로 판정합니다.

| 외부 목록과 제품 관점 | 대응과 확인할 점 |
| --- | --- |
| 첫 이용자, 이미 설치한 이용자, 알림을 거절한 이용자 | 설치 안내·직접 허용·거절 뒤 설정·미지원·기존 아이콘 유지에 대응합니다. REQ-640~643·671·674. |
| 잠금·집중 모드 이용자, 계정을 바꾼 기기 사용자 | 권한과 OS 표시 조건을 구분합니다. 잠금 해제 뒤 대상 확인, 인증 만료·다른 계정·오프라인·이미 처리된 전화, 미리보기 보호를 확인합니다. REQ-657~668. |
| 두 플랫폼을 쓰는 친구, 구독을 철회한 친구, 운영 담당자 | 기기별 권한, 계정 연결과 해제·갱신, 수명주기와 만료, 한 방·한 전화, 민감값 없는 운영 기록을 확인합니다. REQ-644~650·655~656·661·667~670. |

이 목록은 승인 C의 범위와 함께 검토했습니다. 기술 계약과 실기기에서 새로운 제품 선택이 필요한 경우 기존 승인과 달라지는 항목을 별도 체크포인트에 올립니다.
