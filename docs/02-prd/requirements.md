## 겹침·충돌·열린 질문

- REQ-019는 D8로 정했어요(동희님 2026-11-12 12:36 KST 결정 카드). 처음 제안 '30분 뒤 조용히 끊기'는 REQ로 두지 않아요.
- REQ-011(마롱이는 먼저 끊지 않음)과 REQ-015·020·051(시스템이 끝냄)은 충돌하지 않아요. 끝내는 주체가 마롱이(모델)가 아니라 현경님 화면 상태·비용 안전장치이고, 마롱이에게는 끊는 도구가 없어요. 그때 화면은 마롱이 말투로 이유를 짧게 알려요.
- REQ-021(같은 마롱이)과 카톡 `prompt.md`의 '19금·야한 얘기' 절은 통화에서 그대로 갈 수 없어요. 통화는 OpenAI 모델이 말하고, OpenAI 문서는 안전 필터가 세션을 끝낼 수 있다고 해요(사실). 그래서 통화 지시문은 수위를 낮춰요(추정: 정책에 걸리는 정도는 첫 시험에서 확인).
- REQ-044(통화 내용 공유 안 함)는 카톡의 공유 메모 설계와 다르게 가요. 현경님이 통화에서 동희님 얘기를 할 수 있어서예요. 동희님이 다르게 원하면 바꿔요.
- REQ-045는 카톡 마롱이 본체를 조금 고쳐요(답 만들 때 읽는 블록 하나). D3의 '카톡 본체는 그대로'는 LangGraph를 넣지 않는다는 뜻으로 읽었어요.
- REQ-062의 소리 크기는 휴대폰 브라우저 안에서만 재고 보내거나 저장하지 않아요. 그래서 REQ-034(원음 저장 안 함)와 부딪치지 않아요.
- REQ-063은 마롱이 문장만 OpenAI 작은 모델(AI-5)에 한 번 더 보내요. 현경님 말과 기억은 보내지 않고, 문장과 고른 느낌은 저장하지 않아요. 통화 음성이 이미 OpenAI를 지나므로(D2) 새 업체는 없어요. 다르게 원하시면 끌 수 있어요(설정 `CALL_MOOD_MODEL`을 비움).
- REQ-061~064는 Should예요. 얼굴이 없어도 통화는 되니까, 늦어지면 얼굴 없이 먼저 내보낼 수 있어요.
