## 겹침·충돌·열린 질문

- REQ-019는 D8로 정했어요(동희님 2026-11-12 12:36 KST 결정 카드). 처음 제안 '30분 뒤 조용히 끊기'는 REQ로 두지 않아요.
- REQ-011(마롱이는 먼저 끊지 않음)과 REQ-015·020·051(시스템이 끝냄)은 충돌하지 않아요. 끝내는 주체가 마롱이(모델)가 아니라 현경님 화면 상태·비용 안전장치예요. 그때 화면은 마롱이 말투로 이유를 짧게 알려요.
- REQ-076(끊어 달라면 끊기)도 REQ-011과 충돌하지 않아요. 마롱이는 현경님이 부탁할 때만 끊고, 끊기 도구를 불러도 서버가 그 통화의 현경님 말에 끊어 달라는 말이 있는지 먼저 확인해요(SPEC-041). 그래서 마롱이가 잘못 판단해도 부탁 없이는 끊기지 않아요. 디스코드 음성의 '앱이 임의로 끝내지 않음'(디스코드 설계 REQ-070)도 그대로예요.
- REQ-021(같은 마롱이)과 카톡 `prompt.md`의 '19금·야한 얘기' 절은 통화에서 그대로 갈 수 없어요. 통화는 OpenAI 모델이 말하고, OpenAI 문서는 안전 필터가 세션을 끝낼 수 있다고 해요(사실). 그래서 통화 지시문은 수위를 낮춰요(D13, 검토 카드로 추천안. 추정: 정책에 걸리는 정도는 첫 시험에서 확인).
- REQ-044(통화 내용 공유 안 함)는 카톡의 공유 메모 설계와 다르게 가요. 현경님이 통화에서 동희님 얘기를 할 수 있어서예요. 동희님이 다르게 원하면 바꿔요.
- REQ-045는 카톡 마롱이 본체를 조금 고쳐요(답 만들 때 읽는 블록 하나). D3의 '카톡 본체는 그대로'는 LangGraph를 넣지 않는다는 뜻으로 읽었어요.
- REQ-062는 마롱이가 말하는 중인지 알려고 소리 크기를 재요. 휴대폰 브라우저 안에서만 재고 보내거나 저장하지 않아요. 그래서 REQ-034(원음 저장 안 함)와 부딪치지 않아요. 입 모양은 소리 크기를 따르지 않고 GPT talk GIF의 순서를 따라요(D15).
- REQ-063은 마롱이가 한 문장만 OpenAI 작은 모델(AI-5)에 한 번 더 보내요. 현경님 자막과 기억 줄은 따로 보내지 않지만, 마롱이 문장 안에 현경님 얘기가 섞일 수 있어요(검토 F22). 문장과 고른 느낌은 저장하지 않아요. 통화 음성이 이미 OpenAI를 지나므로(D2) 새 업체는 없어요. 다르게 원하시면 끌 수 있어요(설정 `CALL_MOOD_MODEL`을 비움).
- REQ-061\~064는 Should예요. 얼굴이 없어도 통화는 되니까, 늦어지면 얼굴 없이 먼저 내보낼 수 있어요.
- REQ-026·034와 sideband: 서버가 붙는 sideband에는 입력·출력 원음 사본이 와요(사실, OpenAI 'Voice server controls' 안내). 음성 길은 그대로 휴대폰↔OpenAI이고 서버는 사본을 풀지 않고 버려요(SPEC-006). 그래서 약속은 '받지 않는다'가 아니라 '저장·기록하지 않는다'예요(검토 F3).
- 독립 검토 반영(위 '검토'): REQ-014(F5), REQ-015(F5·F11), REQ-019(F4), REQ-026(F3, 문구), REQ-029·042(F6), REQ-039(F10), REQ-043(F13)을 고치고 REQ-066(F11)을 더했어요. 어느 항목을 어디에 반영했는지는 [`docs/call-design.md`](../call-design.md) 11절에 있어요.
- REQ-065(D16)는 목소리 고르기와 지시문으로 맞춰요. GPT-Live 문서의 추가 목소리 21개 중 언어가 한국어로 적힌 것은 `noeul`(여성) 하나뿐이고, 나이 느낌은 적혀 있지 않아요(사실, OpenAI 'Managing sessions' 문서 2026-11-12). 기본 목소리 `marin`이나 다른 언어로 적힌 목소리는 한국어 발음을 들어 봐야 알고(문서도 쓰려는 언어로 들어 보라고 해요), 설명으로 만드는 목소리(prompt-to-voice)는 문서에 `gpt-live-1`이 영어 억양의 맞춤 목소리를 지원한다고만 적혀 있어 한국어로 쓸 수 있는지 알 수 없어요. 그래서 `noeul`에 지시문 '목소리' 절(어른스럽고 차분하게, 아이 같은 톤 없이)을 더하고, 첫 시험 통화에서 동희님이 들어 봐요. 어리게 들리면 지시문을 고쳐 다시 듣고, 그래도 안 되면 다시 여쭤요.
