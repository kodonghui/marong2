# 화면 정의(08단계)

원본: 이 폴더의 `SCR-001.md`\~`SCR-005.md`. 와이어프레임(상태 38개, 폭 360px·430px)과 09단계 목업 후보 두 안은 Claude 디자인 캔버스 [마롱이 통화 화면 설계](https://claude.ai/artifact/FDFCuk2xc8JE8SCUuh7hL2)에 그려요. 캔버스는 비공개라 공유받은 사람만 열 수 있어요. 캔버스와 이 정의가 다르면 이 정의가 맞아요(`.corthex/project.json` 08 메모). 색·간격 값의 원본은 [`design/base.tokens.json`](../../design/base.tokens.json)이에요.

공통 규칙:

- 지원 폭: 세로 휴대폰 360\~430px. 와이어프레임은 360px과 430px 두 폭으로 그려요. 가로 화면은 지원하지 않아요(manifest `portrait`).
- 글: 반말, 마롱이 말투(REQ-021). 오류 문구의 기본은 06 API `x-corthex.errors`의 `message`예요.
- 401: 통화 중이 아니면 페이지를 새로 불러 Access 로그인으로 가요. 통화 중이면 통화를 끊지 않아요(SPEC-027).
- 403 `not_allowed`: "이 계정으로는 마롱이랑 통화할 수 없어"와 '다른 계정으로 들어가기'(Access 로그아웃 주소).
- 503·`default`·시간 넘김·네트워크 없음: 짧은 말과 '다시 해 볼게' 버튼. 화면의 다른 부분은 그대로 써요.
- 시간: 한국 시각. 통화 중 화면에는 통화 시간을 보이지 않아요(P1, 요구사항 '범위 동결 전 빠진 것 찾기').
- 테마: 한국 시각 08:00부터 20:00 직전까지 군밤 크림, 나머지는 밤하늘이에요. 화면을 열어 둔 채 경계 시각을 지나거나 앱으로 돌아와도 통화와 글 입력을 유지하며 화면만 바꿔요.
- 같은 버튼을 두 번 누르기: 요청이 도는 동안 버튼을 막아요(경우의 종류 '반복').
- 마롱이 얼굴(TERM-018): 통화 홈과 통화 중 화면의 얼굴은 기능 명세 3.5 '얼굴 규칙'을 따라요(SPEC-029, SPEC-030). 그림은 동희님이 올린 표정 그림 17장과 GPT GIF에서 가져온 입·눈 조합 4장(모두 21장)이고 쓰임은 [`design/marong-face/README.md`](../../design/marong-face/README.md)에 있어요. 그림은 꾸밈이라 `alt=""`이고 상태는 늘 글로도 보여요. 말할 때 입은 동희님이 고른 GPT talk 움직임이에요(D15). 움직임 줄이기를 켜면 깜빡임·숨쉬기·튀기·talk 움직임을 끄고, 말하는 동안은 입 조금(15)으로 멈춰 둬요. 그림을 못 받으면 빈 원으로 두고 통화는 그대로예요(REQ-064). 크기: 통화 중 248px, 홈 200px, 끝난 화면 152px(토큰 `size.face-*`).

## 마롱이의 일기와 듣기 시험(2026-11-16 설계, 아직 만들지 않음)

원본: 이 폴더의 `SCR-113.md`\~`SCR-119.md`와 `SCR-001.md`의 예산 상태(FL-121). 회색 와이어프레임(상태 68개, 폭 360px·430px)은 [마롱이의 일기 와이어프레임](https://claude.ai/artifact/SnzgPx64NHhxgcxpa3HRho)이고, 그 원본은 이 폴더의 [`wireframes-diary.html`](wireframes-diary.html)이에요. 09단계 목업은 Claude 디자인 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)에 있어요. 두 후보 중 A 그림일기장으로 정했고(2026-11-16 21:44 KST), 화면 정의의 상태를 A로 그렸어요(대지 72장). 화면마다 어느 대지인지, 따로 그리지 않은 상태와 그 이유는 각 정의의 '목업' 줄에 있어요. 고르지 않은 B 후보 4장은 비교 기록으로 캔버스 맨 아래에 남겼어요. 후보의 차이, 결정, 더한 토큰과 대비는 [`design/diary-candidates.md`](../../design/diary-candidates.md)에 적었어요. 둘 다 비공개라 공유받은 사람만 열 수 있고, 다르면 이 폴더의 정의가 맞아요.

`/chat/` 아래 화면의 공통 규칙(위 공통 규칙에 더해):

- 문: 글 대화(SCR-107)와 같은 Access 앱과 같은 계정 확인(`/chat/api/me`)을 써요. 통화하는 친구이고 디스코드 DM 연결이 있어야 하고, 자기 일기만 봐요.
- 앱: 앱 0.2.1에서는 글 대화 창 안에서 열려요. 그 창의 뒤로 가기는 창을 닫으니까 일기장 머리 왼쪽에 '글 대화' 버튼을 둬요([app-chat.md](../app-chat.md)의 앱 창 규칙). 앱은 바꾸지 않아요.
- 칸: 고치기(`#fix`)·다시 그리기(`#redraw`)는 한 날 위에 아래에서 올라오는 칸, 달력(`#calendar`)·숨긴 일기(`#hidden`)·내 모습 카드(`#look`)는 화면 가득 열리는 칸이에요. 주소의 `#` 뒤는 서버로 가지 않아서 06 API와 터널 규칙이 그대로이고, 브라우저 뒤로 가기는 칸을 닫아요.
- 401: 쓴 말·고른 것을 남기고 페이지를 새로 불러 Access 로그인으로 가요. 403 `not_allowed`: "이 계정으로는 일기장을 열 수 없어"(듣기 시험은 "이 계정으로는 시험을 볼 수 없어"), `no_dm`: "디스코드 DM에서 마롱이한테 먼저 말 걸어 줘", `cross_site`: "이 화면에서 다시 해 줘"이고 저절로 다시 보내지 않아요.
- 503: 화면을 그대로 두고 위에 띠 "잠깐 문제가 생겼어. 조금 있다가 다시 해 줘", 불러오기는 5초부터 30초까지 늘려 가며 다시 해요. `default`·네트워크 없음·시간 넘김: "잠깐 문제가 생겼어. 다시 해 볼래?", '다시 해 볼게'(또는 '다시 보내기'), 추적 id.
- 친구가 쓴 말(고칠 말, 바꿀 점)은 `textContent`로만 보이고, 실패해도 칸에 그대로 남아요. 멱등 키는 누를 때마다 새로 만들고, 답 없이 끊겼을 때만 같은 키로 다시 보내요(SCR-114).
- 그림(`<img>`)과 소리(`<audio>`)는 상태 번호를 읽지 못해요. 그림 실패는 모두 기본 그림과 '그림 다시 보기'(SCR-113), 소리 실패는 그 줄의 "그 소리를 찾지 못했어"와 시험 다시 불러오기예요(SCR-119).
- 원고지: 한 칸에 한 글자, 칸은 32\~34px, 줄의 칸 수는 ⌊(폭 − 32px) ÷ 32px⌋이라 360px에서 10칸, 430px에서 12칸이에요. 첫 칸은 비우고, 줄 첫 칸에 오는 띄어쓰기는 건너뛰어요. 원고지는 화면 읽기 프로그램에서 숨기고(`aria-hidden`) 같은 글을 읽기용 문단으로 따로 둬요.
- 테마: 통화 화면과 같은 시간 규칙(08:00\~20:00 직전 군밤 크림, 그 밖 밤하늘)이에요. 일기장 종이·원고지 줄·도장 색은 09단계에서 정해 토큰에 넣어요.
