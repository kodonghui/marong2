Purpose: 현경님이 앱을 열자마자 한 번 눌러 마롱이에게 전화를 걸고, 지난 통화와 기억으로 가는 곳이에요. (FL-001, FL-002, FL-006, FL-007, FL-008, FL-009, FL-121)

| SCR-001#error | 슬픈 얼굴(06), "잠깐 문제가 생겼어. 조금 있다 다시 해 줘"와 '다시 해 볼게'. 마지막 통화 줄만 실패하면 그 줄만 숨김 | API-001#503, API-001#default, API-006#400, API-006#503, API-006#default, API-124#default, 네트워크 없음. API-107#default는 통화 화면의 연결 확인 중(SCR-002#reconnecting) |

- empty: 홈은 늘 통화 버튼이 있어 비지 않아요. 통화가 한 번도 없으면 마지막 통화 줄만 숨겨요.
- stale: 앱으로 돌아올 때(`visibilitychange`) API-001을 다시 불러 진행 중 통화·예산을 맞춰요. 따로 보이는 상태는 없어요.
- 예산 달: UTC 기준이라 한국 시각으로 매달 1일 오전 9시에 풀려요(FL-009). #budget은 그때까지 이어지고, 1일 0\~9시에도 '다음 달에' 문구는 그대로 둬요(독립 검토 F12). OpenAI 쪽 지출 한도에 걸려도 같은 #budget이에요(SPEC-023).
- 얼굴: 상태마다 기능 명세 3.5 표 1의 얼굴이에요(SPEC-029). 그림을 못 받으면 빈 원으로 두고 통화 버튼은 그대로예요(REQ-064).
- 경우의 종류: 접근(#permission), 한도(#budget), 바깥 서비스(#error, 얼굴 그림을 못 받음), 데이터 노출(예산 금액·80% 경고 없음, SPEC-002), 반복(통화 버튼은 누르면 바로 막힘).
- 지금 통화(Gemini 길)의 통화 버튼: API-107#101(웹소켓으로 바뀜)이면 통화 화면 SCR-002#connecting부터예요.
- 지금 통화의 예산(FL-121, 2026-11-16): 이번 달 비용을 셀 수 없으면 막지 않아서(REQ-185) 홈은 #normal 그대로예요. 하던 통화의 다시 잇기와 글로 갈아타기는 막지 않아요(REQ-049). 120%면 마롱이가 한 문장으로 인사하고 `hangup`으로 끝난 뒤 홈이 #budget이에요(REQ-183). 디스코드 음성방은 소리 안내뿐이라 화면이 없어요(SPEC-175).
- 목업(09단계, 2026-11-16): FL-121의 #budget은 일기 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)의 'SCR-001#budget · 밤하늘 · 360px' 대지(`A001-budget.dc.html`)예요. 통화 토큰(`color.a`·`color.b`)으로 지금 통화의 끝 문장 "글로는 계속 얘기할 수 있어"와 '글 대화' 버튼을 그렸어요. 다른 상태의 목업은 위 README의 통화 캔버스에 있어요.
