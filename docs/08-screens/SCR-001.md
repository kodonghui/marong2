# SCR-001 통화 홈

Purpose: 현경님이 앱을 열자마자 한 번 눌러 마롱이에게 전화를 걸고, 지난 통화와 기억으로 가는 곳이에요. (FL-001, FL-002, FL-006, FL-007, FL-008, FL-009)

| Data | Source |
| --- | --- |
| 친구 이름, 새 통화 가능 여부, 진행 중 통화 | API-001 |
| 마지막 통화 한 줄(때, 길이, 정리 상태, 제목) | API-006 (`limit=1`) |

| Action | Result | Failure |
| --- | --- | --- |
| 통화 버튼 | SCR-002#connecting으로 가서 통화를 걺(SPEC-003) | 마이크 거절 → SCR-002#mic-denied. 예산 → 이 화면 #budget |
| 이어 받기(다른 화면에서 통화 중일 때) | SCR-002로 가서 넘겨받음(SPEC-009) | 429 `takeover_limit` → 안내 한 줄 |
| '통화 중' 띠 누르기(이 화면이 통화 중일 때) | SCR-002로 돌아감 | 없음 |
| 마지막 통화 줄 | SCR-004 | 없음 |
| 지난 통화 · 마롱이 기억 | SCR-003 · SCR-005 | 없음 |
| Chrome으로 열기(카톡 안 브라우저) | Chrome에서 같은 주소를 엶 | 열리지 않음 → 주소를 복사하는 버튼 |

| State | What the user sees and can do | From responses |
| --- | --- | --- |
| SCR-001#loading | 인사 줄과 통화 버튼 자리에 회색 모양. 버튼은 못 누름 | |
| SCR-001#normal | "현경아, 마롱이한테 전화할래?"와 큰 통화 버튼, 마지막 통화 한 줄, 지난 통화·마롱이 기억 | API-001#200, API-006#200 |
| SCR-001#active-elsewhere | "다른 화면에서 마롱이랑 통화 중이야"와 '여기서 이어 받기' | API-001#200(`activeCall.thisClient=false`) |
| SCR-001#in-call | 위에 '마롱이랑 통화 중' 띠(누르면 SCR-002). 통화 버튼 대신 띠 | API-001#200(`activeCall.thisClient=true`) |
| SCR-001#budget | 마롱이 말투로 "이번 달 통화는 여기까지야. 다음 달에 또 걸어 줘. 카톡으로는 계속 얘기할 수 있어!"(REQ-050). 통화 버튼 막힘. 금액은 보이지 않음 | API-001#200(`blockedReason=budget`), API-002#429(`budget_exhausted`, `budget_hard_stop`) |
| SCR-001#in-app | "카톡 안에서는 통화가 잘 안 돼. Chrome으로 열어 줘"와 'Chrome으로 열기' | (화면이 UA로 판단) |
| SCR-001#permission | 401 → Access 로그인 화면(새로 불러옴). 403 → "이 계정으로는 마롱이랑 통화할 수 없어"와 '다른 계정으로 들어가기' | API-001#401, API-001#403, API-006#401, API-006#403 |
| SCR-001#error | "잠깐 문제가 생겼어. 조금 있다 다시 해 줘"와 '다시 해 볼게'. 마지막 통화 줄만 실패하면 그 줄만 숨김 | API-001#503, API-001#default, API-006#400, API-006#503, API-006#default, 네트워크 없음 |

- empty: 홈은 늘 통화 버튼이 있어 비지 않아요. 통화가 한 번도 없으면 마지막 통화 줄만 숨겨요.
- stale: 앱으로 돌아올 때(`visibilitychange`) API-001을 다시 불러 진행 중 통화·예산을 맞춰요. 따로 보이는 상태는 없어요.
- 경우의 종류: 접근(#permission), 한도(#budget), 바깥 서비스(#error), 데이터 노출(예산 금액·80% 경고 없음, SPEC-002), 반복(통화 버튼은 누르면 바로 막힘).
