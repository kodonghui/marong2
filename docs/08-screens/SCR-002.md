# SCR-002 통화 중

Purpose: 마롱이와 친구처럼 통화하고, 끊김·쉬기·넘겨받기가 있어도 현경님이 신경 쓸 일이 없게 하는 화면이에요. (FL-002~FL-007, FL-009)

| Data | Source |
| --- | --- |
| 통화 id, 구간 id, answer SDP | API-002, API-003 |
| 할 일(`none`·`rest`·`taken_over`·`ended`), 끝난 이유 | API-004 |
| 마롱이 목소리, 말하는 중 표시(소리 크기) | WebRTC(휴대폰↔OpenAI, API 아님) |
| 닫힘 알림 | 데이터 채널 `session.closed`(API 아님) |

| Action | Result | Failure |
| --- | --- | --- |
| 음소거 / 음소거 풀기 | 마이크 트랙을 끄고 켬(REQ-060). 버튼이 눌린 모양과 '음소거 중' | 없음(로컬 동작) |
| 끊기 | 바로 소리를 끊고 API-005, #ended로(SPEC-011) | 네트워크 실패 → 그래도 #ended(서버는 신호 2분 뒤 끝냄) |
| 깨우기(쉬는 중) | API-003 `wake`, #waking → #talking(SPEC-008) | 409 `stale_segment` → 무시하고 신호로 맞춤. 503 → 2초·5초 뒤 다시 |
| 여기서 받기(#taken-over) | API-002로 넘겨받음 → #connecting | 429 `takeover_limit` → 안내 한 줄 |
| 다시 걸기(#ended·#error) | API-002로 새 통화 → #connecting | 같은 응답 규칙 |
| 뒤로 가기 | SCR-001#in-call(통화는 이어짐) | 없음 |

| State | What the user sees and can do | From responses |
| --- | --- | --- |
| SCR-002#connecting | 마롱이 얼굴, "마롱이한테 거는 중…", 끊기 | (API-002 요청 중) |
| SCR-002#talking | 마롱이 얼굴과 말할 때 움직이는 표시, 음소거·끊기. 통화 시간은 없음 | API-002#201, API-002#200, API-003#201(`reconnect`), API-004#200(`none`) |
| SCR-002#reconnecting | "잠깐 끊겼어, 다시 잇는 중…", 끊기. 마롱이는 이어지면 인사 없이 이어 감 | (닫힘 알림 뒤 API-004#200 `none` → API-003 요청 중), API-003#503(다시 하는 동안) |
| SCR-002#resting | "조용해서 잠깐 쉬는 중이야. 말하면 바로 이어져", 깨우기·끊기. 마이크가 멈추면 "말하려면 깨우기를 눌러 줘" (SPEC-008) | API-004#200(`rest`) |
| SCR-002#waking | "다시 이어지는 중…", 끊기 | (API-003 `wake` 요청 중) |
| SCR-002#taken-over | "다른 화면에서 통화 중이야", '여기서 받기'·'홈으로' | API-004#200(`taken_over`), API-003#409(`taken_over`), API-005#409(`taken_over`) |
| SCR-002#mic-denied | "마이크를 허용해야 통화할 수 있어"와 허용하는 법(주소창 자물쇠 → 권한 → 마이크), '다시 해 볼게' | (getUserMedia 거절) |
| SCR-002#ended | "통화 끝났어"와 이유 한 줄(아래 표), 다시 걸기·지난 통화 보기·홈 | API-005#200, API-004#200(`ended`), API-003#409(`call_ended`), API-003#429 |
| SCR-002#error | 오류 코드의 말(예: "마롱이가 지금 전화를 못 받아. 조금 있다 다시 걸어 줘"), 다시 걸기·홈 | API-002#400, API-002#503, API-002#default, API-003#400, API-003#404, API-003#default, API-004#400, API-004#404, API-005#400, API-005#404, 네트워크 없음(통화 전) |
| SCR-002#permission | 통화 전 401 → 새로 불러 로그인. 통화 중 401 → 통화는 그대로, 끝나면 #ended에 "다시 들어와 줘"와 '다시 들어가기'. 403 → "이 계정으로는 마롱이랑 통화할 수 없어" | API-002#401, API-002#403, API-003#401, API-003#403, API-004#401, API-004#403, API-005#401, API-005#403 |

#ended의 이유 한 줄:

| 끝난 이유 | 보이는 말 |
| --- | --- |
| `hangup` | (없음) |
| `beat_lost` | "연결이 끊겨서 통화가 끝났어" |
| `reconnect_limit` | "연결이 자꾸 끊겨서 잠깐 끊었어. 다시 걸어 줘" |
| `budget_hard_stop` | "이번 달 통화는 여기까지야. 다음 달에 또 걸어 줘. 카톡으로는 계속 얘기할 수 있어!" |
| `admin` | "통화가 끝났어" |

다르게 가는 응답:

- API-002#409(`already_connecting`): 화면에 보이지 않아요. 먼저 보낸 걸기의 결과를 기다려요.
- API-002#429(`budget_exhausted`·`budget_hard_stop`): SCR-001#budget으로 돌아가요.
- API-002#429(`takeover_limit`): #taken-over에 "화면을 너무 자주 옮겼어. 조금 있다 다시 걸어 줘".
- API-003#409(`stale_segment`): 보이지 않아요. 신호를 바로 보내 상태를 맞춰요.
- API-003#503·API-004#503·API-004#default: #reconnecting을 유지하며 2초·5초 뒤 다시, 세 번 다 실패하면 끊기를 보내고 #ended(이유 `beat_lost`의 말).
- API-005#503·API-005#default: 그래도 #ended로 가요(서버는 신호 2분 뒤 끝냄).

- loading: #connecting·#waking이 맡아요. empty: 통화 화면에는 빈 상태가 없어요. stale: #taken-over가 맡아요.
- 경우의 종류: 접근(#permission), 상태 변화(#ended·#taken-over), 반복(버튼은 요청 중 막힘), 동시(#taken-over), 한도(#ended 이유), 바깥 서비스(#reconnecting·#error), 데이터 노출(통화 id 말고 아무것도 보이지 않음), AI 답(마롱이 말은 목소리로만, 금지 질문은 지시문이 다룸).
