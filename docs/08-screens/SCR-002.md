# SCR-002 통화 중

Purpose: 마롱이와 친구처럼 통화하고, 끊김·쉬기·넘겨받기가 있어도 현경님이 신경 쓸 일이 없게 하는 화면이에요. (FL-002~FL-007, FL-009)

| Data | Source |
| --- | --- |
| 통화 id, 구간 id, answer SDP | API-002, API-003 |
| 할 일(`none`·`rest`·`taken_over`·`ended`), 끝난 이유 | API-004 |
| 마롱이 목소리 | WebRTC(휴대폰↔OpenAI, API 아님) |
| 마롱이 얼굴 그림 21장 | 정적 파일 `/static/face/v1/*.webp`(API 아님, 홈에서 미리 받음, SPEC-029) |
| 소리 크기(마롱이 목소리·현경님 마이크, 누가 말하는 중인지만 봄) | 브라우저 안에서만 잼(`AnalyserNode`). 보내거나 저장하지 않음(REQ-034, SPEC-029) |
| 마롱이 자막 조각 | 데이터 채널 `session.output_transcript.delta`(API 아님) |
| 느낌(얼굴에만 씀) | API-012(SPEC-030) |
| 닫힘 알림 | 데이터 채널 `session.closed`(API 아님) |

| Action | Result | Failure |
| --- | --- | --- |
| 음소거 / 음소거 풀기 | 마이크 트랙을 끄고 켬(REQ-060). 버튼이 눌린 모양과 '음소거 중' | 없음(로컬 동작) |
| 끊기 | 바로 소리를 끊고 API-005, #ended로(SPEC-011) | 네트워크 실패 → 그래도 #ended(서버는 신호 2분 뒤 끝냄) |
| 깨우기(쉬는 중) | API-003 `wake`, #waking → #talking(SPEC-008) | 409 `stale_segment` → 무시하고 신호로 맞춤. 503 → 2초·5초 뒤 다시 |
| 여기서 받기(#taken-over) | API-002로 넘겨받음 → #connecting | 429 `takeover_limit` → 안내 한 줄 |
| 다시 걸기(#ended·#error) | API-002로 새 통화 → #connecting | 같은 응답 규칙 |
| 뒤로 가기 | SCR-001#in-call(통화는 이어짐) | 없음 |

#ended의 이유 한 줄:

| 끝난 이유 | 보이는 말 | 얼굴 |
| --- | --- | --- |
| `hangup` | (없음) | 01 |
| `beat_lost` | "연결이 끊겨서 통화가 끝났어" | 13 |
| `reconnect_limit` | "연결이 자꾸 끊겨서 잠깐 끊었어. 다시 걸어 줘" | 13 |
| `budget_hard_stop` | "이번 달 통화는 여기까지야. 다음 달에 또 걸어 줘. 카톡으로는 계속 얘기할 수 있어!" | 06 |
| `admin` | "통화가 끝났어" | 01 |

다르게 가는 응답:

- API-002#409(`already_connecting`): 화면에 보이지 않아요. 먼저 보낸 걸기의 결과를 기다려요.
- API-002#429(`budget_exhausted`·`budget_hard_stop`): SCR-001#budget으로 돌아가요.
- API-002#429(`takeover_limit`): #taken-over에 "화면을 너무 자주 옮겼어. 조금 있다 다시 걸어 줘".
- API-003#409(`stale_segment`): 보이지 않아요. 신호를 바로 보내 상태를 맞춰요.
- API-003#503·API-004#503·API-004#default: #reconnecting을 유지하며 2초·5초 뒤 다시, 세 번 다 실패하면 끊기를 보내고 #ended(이유 `beat_lost`의 말).
- API-005#503·API-005#default: 그래도 #ended로 가요(서버는 신호 2분 뒤 끝냄).
- API-012(느낌 고르기)의 실패는 화면에 보이지 않고 상태도 바꾸지 않아요. 얼굴만 그대로 둬요(REQ-064, SPEC-030). API-012#400·API-012#404·API-012#409·API-012#default는 그 문장을 버려요. API-012#429는 그 문장을 버리고 다음 문장부터 다시 보내요. API-012#503이 한 구간에서 3번 이어 오면 그 구간 동안 보내지 않아요. API-012#401·API-012#403도 통화를 끊지 않고 신호(API-004)의 결과를 따라요.

- loading: #connecting·#waking이 맡아요. empty: 통화 화면에는 빈 상태가 없어요. stale: #taken-over가 맡아요.
- 얼굴: 상태마다 기능 명세 3.5 표 1의 얼굴이에요(SPEC-029). 그림은 꾸밈이라 `alt=""`이고 상태는 늘 글로도 보여요. 움직임 줄이기를 켜면 깜빡임·숨쉬기·튀기·talk 움직임이 없고, 마롱이가 말하는 동안은 입 조금(15)으로 멈춰 둬요. 원격 소리를 잴 수 없으면 자막 조각이 오는 동안 같은 talk 움직임을 보여요.
- 경우의 종류: 접근(#permission), 상태 변화(#ended·#taken-over), 반복(버튼은 요청 중 막힘, 느낌 요청은 한 번에 하나), 동시(#taken-over), 한도(#ended 이유, 느낌 요청 한도는 보이지 않음), 바깥 서비스(#reconnecting·#error, 느낌 고르기 실패는 얼굴 그대로), 데이터 노출(통화 id 말고 아무것도 보이지 않음, 소리 크기는 보내지 않음), AI 답(마롱이 말은 목소리로만, 금지 질문은 지시문이 다룸, 느낌이 틀려도 얼굴만 바뀜).
