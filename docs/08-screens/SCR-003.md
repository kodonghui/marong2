# SCR-003 지난 통화

Purpose: 지난 통화를 최근순으로 보고 하나를 골라 상세로 가는 화면이에요. (FL-008)

| Data | Source |
| --- | --- |
| 통화 목록(때, 길이, 상태, 정리 상태, 제목), 다음 커서 | API-006 |

| Action | Result | Failure |
| --- | --- | --- |
| 통화 한 줄 누르기 | SCR-004 | 없음 |
| 더 보기 | 다음 20개를 아래에 붙임 | 실패 → 그 버튼 자리에 '다시 해 볼게' |
| 당겨서 새로 고침 | 목록을 처음부터 다시 | 실패 → #error, 보던 목록은 둠 |

| State | What the user sees and can do | From responses |
| --- | --- | --- |
| SCR-003#loading | 줄 모양 회색 6개 | |
| SCR-003#normal | 줄마다 "11월 12일 (목) 오후 9:00 · 42분"과 제목. 정리 중이면 "정리하고 있어…", 실패면 "정리를 못 했어", 짧은 통화면 "짧은 통화", 진행 중이면 '통화 중' 표시 | API-006#200 |
| SCR-003#empty | "아직 마롱이랑 통화한 적이 없어"와 '전화하기'(SCR-001) | API-006#200(`items=[]`) |
| SCR-003#error | "잠깐 문제가 생겼어. 조금 있다 다시 해 줘"와 '다시 해 볼게' | API-006#400, API-006#503, API-006#default, 네트워크 없음 |
| SCR-003#permission | 401 → 로그인. 403 → "이 계정으로는 마롱이랑 통화할 수 없어" | API-006#401, API-006#403 |

- stale: 상세에서 지우고 돌아오면 목록을 다시 불러요. 따로 보이는 상태는 없어요.
- 긴 글: 제목은 40자까지(서버가 자름), 한 줄을 넘으면 두 줄까지 보이고 말줄임.
- 경우의 종류: 접근, 빈 답(#empty), 바깥 서비스(#error), 데이터 노출(목록에 자막·기억 내용 없음).
