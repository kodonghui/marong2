# SCR-004 통화 상세

Purpose: 통화 하나의 카드·통화 기억·자막을 보고, 통화나 기억을 지우는 화면이에요. (FL-007, FL-008)

| Data | Source |
| --- | --- |
| 통화(때, 길이, 끝난 이유, 정리 상태), 카드, 이 통화 기억, 자막 또는 자막 지운 때, 카드·자막 줄의 잊기 표시(`forgotten`) | API-007 |

| Action | Result | Failure |
| --- | --- | --- |
| 자막 펼치기 | 자막을 순서대로 보임(마롱이·현경 말풍선) | 없음 |
| 기억 하나 지우기 | 확인 시트 "이 기억 지울까? 이 얘기는 내가 먼저 꺼내지 않을게. 카톡에서 한 얘기는 그대로야" → API-010 → 그 줄이 빠지고 API-007을 다시 불러 카드 항목·잊기 표시를 맞춤(SPEC-021, 기능 명세 3.7) | 404 → "이미 지워졌어" 하고 줄을 뺌. 그 밖 → 줄 옆에 '다시 해 볼게' |
| 이 통화 지우기 | 확인 시트 "이 통화를 지울까? 여기 있는 자막·카드·기억이 지워지고 되돌릴 수 없어. 카톡에서 나눈 얘기는 그대로야" → API-008 → SCR-003으로(SPEC-020) | 409 → #call-active. 404 → "이미 지워졌어" 하고 SCR-003 |

| State | What the user sees and can do | From responses |
| --- | --- | --- |
| SCR-004#loading | 카드·기억·자막 자리에 회색 모양 | |
| SCR-004#normal | 카드(요약, 정한 것, 안 정한 것, 할 일, 다음에 물어볼 것), 이 통화 기억(줄마다 지우기), 자막 펼치기, 이 통화 지우기. 잊기 표시(`forgotten`)가 있는 카드 요약과 자막 줄은 흐린 글씨에 '잊기로 한 얘기' 꼬리표(통째로 지우려면 이 통화 지우기) | API-007#200(`organizeStatus=done`), API-008#204, API-010#204 |
| SCR-004#organizing | 카드 자리에 "통화 정리하고 있어…". 10초마다 다시 불러 3분까지 기다림. 자막은 볼 수 있음 | API-007#200(`pending`·`running`) |
| SCR-004#organize-failed | "정리를 못 했어. 자막은 볼 수 있어" | API-007#200(`failed`) |
| SCR-004#skipped | "짧은 통화라 정리할 게 없었어" | API-007#200(`skipped`) |
| SCR-004#transcript-deleted | 자막 자리에 "180일이 지나서 자막은 지워졌어"(카드·기억은 그대로) | API-007#200(`turns=null`) |
| SCR-004#live | "지금 통화 중이야. 끝나면 정리돼"와 '통화로 돌아가기'. 지우기 버튼 없음 | API-007#200(`status=live`·`resting`) |
| SCR-004#call-active | 지우기 시트에 "통화 끝나고 지울 수 있어" | API-008#409(`call_active`) |
| SCR-004#error | 404 → "이미 지워졌거나 없는 통화야"와 '지난 통화로'. 그 밖 → 짧은 말과 '다시 해 볼게' | API-007#400, API-007#404, API-007#503, API-007#default, API-008#400, API-008#503, API-008#default, API-010#400, API-010#503, API-010#default |
| SCR-004#permission | 401 → 로그인. 403 → "이 계정으로는 마롱이랑 통화할 수 없어" | API-007#401, API-007#403, API-008#401, API-008#403, API-010#401, API-010#403 |

- empty: 기억이 없으면 기억 칸에 "이 통화에서는 따로 기억한 게 없어". 카드 없음은 위 정리 상태들이 맡아요.
- 긴 글: 자막 한 줄 4,000자까지 줄바꿈으로 다 보이고, 카드 요약은 400자까지.
- 경우의 종류: 접근(#permission, 남의 통화는 404로 #error), 대상(#error 404), 상태 변화(#call-active, #live), 반복(지우기 버튼 막힘, 두 번째 404는 지운 것으로 처리), 빈 답(정리 상태들), 데이터 노출(이 통화 것만), AI 답(카드·기억은 정리 모델이 만든 것을 서버가 확인한 뒤 보임).
