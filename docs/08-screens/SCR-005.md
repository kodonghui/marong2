# SCR-005 마롱이 기억

Purpose: 통화에서 마롱이가 기억한 것을 보고, 원하지 않는 기억을 지우는 화면이에요. (FL-008)

| Data | Source |
| --- | --- |
| 통화 기억(내용, 만든 때, 나온 통화), 다음 커서 | API-009 |

| Action | Result | Failure |
| --- | --- | --- |
| 기억 하나 지우기 | 확인 시트 "이 기억 지울까? 마롱이가 다시 꺼내지 않아" → API-010 → 줄이 빠짐(SPEC-021) | 404 → "이미 지워졌어" 하고 줄을 뺌. 그 밖 → 줄 옆에 '다시 해 볼게' |
| 나온 통화 누르기 | SCR-004 | 없음 |
| 더 보기 | 다음 50개를 붙임 | 실패 → '다시 해 볼게' |

| State | What the user sees and can do | From responses |
| --- | --- | --- |

| SCR-005#empty | "아직 통화에서 기억한 게 없어. 통화하다가 '이거 기억해 줘'라고 하면 여기 생겨" | API-009#200(`items=[]`) |
| SCR-005#error | 짧은 말과 '다시 해 볼게' | API-009#400, API-009#503, API-009#default, API-010#400, API-010#503, API-010#default, 네트워크 없음 |
| SCR-005#permission | 401 → 로그인. 403 → "이 계정으로는 마롱이랑 통화할 수 없어" | API-009#401, API-009#403, API-010#401, API-010#403 |

- 다르게 가는 응답: API-010#404는 오류 대신 줄을 빼고 "이미 지워졌어"를 잠깐 보여요.

- 경우의 종류: 접근, 대상(404는 지운 것으로), 반복(지우는 동안 막힘), 빈 답(#empty), 데이터 노출(자기 기억만, 대체된 기억 없음).
