# SCR-113 일기장 한 날

Purpose: 친구가 마롱이가 쓴 하루 일기(글·그림·마음 날씨·도장)를 보고, 앞뒤 날로 넘기고, 고치기·다시 그리기·마음 날씨·도장·숨기기를 하는 곳이에요. (FL-115, FL-116, FL-117, FL-118, FL-119)

주소: `/chat/diary/:date`, 날짜가 없으면(`/chat/diary/`) 가장 최근 일기 날이에요(SPEC-158). 앱에서는 글 대화 창 안에서 열려요. 그 창의 안드로이드 뒤로 가기는 창을 닫아서([app-chat.md](../app-chat.md)의 앱 창 규칙, 앱 0.2.1) 머리 왼쪽에 '글 대화' 버튼을 둬요.

목업(09단계, A 그림일기장): 디자인 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)의 'A · SCR-113#…' 대지 28장이에요. 상태 23개를 모두 그렸어요. #normal은 `Main.dc.html`(430px), #stamped는 `A-stamped-night-360.dc.html`, 나머지는 `A113-<상태>.dc.html`(360px)이에요. 더 그린 경우는 2분 넘게 그리는 중(`A113-redrawing-long`), 그림만 못 받음(`A113-picture-error`), 지난 일기가 있는 #off(`A113-off-past`), DM 연결 없음(`A113-permission-no-dm`), 처음 불러올 때의 #reconnecting(`A113-reconnecting-first`)이에요. 날씨·도장·숨기기가 503·네트워크로 실패할 때의 '짧은 말'은 이 정의에 문구가 없어서 그리지 않았어요. 일기 글과 그림은 예시이고, 캔버스와 이 정의가 다르면 이 정의가 맞아요.

- 원고지: 글(60\~160자)을 한 칸에 한 글자로 써요. 칸 크기 32\~34px, 칸 수는 내용 폭을 32로 나눈 몫(360px 화면 10칸, 430px 12칸). 첫 칸은 비우고, 줄 맨 앞에 오는 띄어쓰기는 쓰지 않아요. 숫자·영문·문장 부호도 한 칸이에요. 160자면 360px에서 16줄이에요. 칸은 그림처럼 그리고(`aria-hidden`) 같은 글을 화면 읽기용 문단으로 한 번 더 넣어요.
- 글과 제목은 `textContent`로만 넣어요. 제목은 20자까지라 360px에서 한 줄을 넘으면 두 줄로 접고, 더 넘치지 않아요.
- 그림: 가로가 긴 그림(SPEC-155)을 폭에 맞춰 보여요. 그림의 `alt`는 "마롱이가 그린 '{제목}' 그림"이에요. 장면(TERM-025)은 화면과 받은 데이터 어디에도 없어요.
- 주소의 날짜가 틀리면(`2026-02-30`, API-110#400) 06 오류 목록의 client(오류 상태와 추적 id)와 달리 #none으로 보여요. 주소를 손으로 바꾼 경우라 '없는 날'과 같은 뜻이어서예요.
- 날짜: 일기 하루(TERM-022) 날짜예요. 새벽 4시 경계 설명은 달력(SCR-116) 아래에만 둬요.
- empty: #empty와 #off. 일기가 있는 친구에게 빈 한 날은 없고, 없는 날은 #none이에요.
- stale: 앱으로 돌아오거나 탭을 다시 볼 때(`visibilitychange`) API-110을 다시 불러요. 고치는 중·그리는 중에는 2초마다 불러요. 다른 기기에서 바꾼 판은 다음 쓰기에서 409 → #stale로 맞춰요.
- 테마: 글 대화와 같아요(08:00\~20:00 군밤 크림, 나머지 밤하늘). 일기장 종이 색은 09단계에서 정해요.
- 경우의 종류: 접근(#permission, 남의 날은 #none, 남의 그림은 기본 그림), 입력(날짜 형식이 틀린 주소 → #none), 대상(#none, 그림 404 → 기본 그림), 상태 변화(#writing·#skipped·#failed, `not_ready` → 그 상태), 반복(누른 버튼은 답이 올 때까지 막음, 날씨·도장·숨기기는 같은 값이면 그대로), 동시(#stale, #fixing, #redrawing), 한도(#limits, 남은 수는 늘 보임), 바깥 서비스(#redraw-failed, #reconnecting, 그림 못 받음은 그 자리만), 데이터 노출(장면·하루 모음·모델 이름·비용 없음), 빈 답과 끊긴 흐름(#empty, #off, 2분 넘는 그리기), 화면 상태(360px·430px 와이어프레임), AI 답(일기 글은 그대로 보이고, 고치기·다시 그리기 실패는 전 판·전 그림 그대로).
