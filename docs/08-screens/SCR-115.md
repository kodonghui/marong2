# SCR-115 다시 그리기

Purpose: 마음에 안 드는 그림을 바꿀 점을 적어서, 또는 그대로 다시 그려 달라고 하는 칸이에요. 지난 그림은 남아요. (FL-116)

주소: `/chat/diary/:date#redraw`. 한 날(SCR-113) 위에 아래에서 올라오는 칸이에요.

| Data | Source |
| --- | --- |
| 지금 판 번호, 남은 다시 그리기 수, 막힌 이유 | API-110 (한 날이 불러 둔 값) |

| Action | Result | Failure |
| --- | --- | --- |
| 바꿀 점 쓰기(안 써도 됨) | 0\~200자, "0/200" | 200자를 넘게 붙여 넣으면 200자에서 자르고 "200자까지 쓸 수 있어" |
| '다시 그려 줘' | API-112(`revision`, `change`, 새 `Idempotency-Key`) → 202 → 칸이 닫히고 SCR-113#redrawing. 끝은 한 날의 `redraw.last`로 봐요(SPEC-161) | 아래 상태들. 실패한 다시 그리기는 횟수에 세지 않아요 |
| 닫기 | 칸이 닫힘. 쓴 말은 이 날을 다시 열 때까지 남음 | 없음 |

| State | What the user sees and can do | From responses |
| --- | --- | --- |
| SCR-115#normal | 제목 "어떻게 다시 그릴까?", 안내 "바꿀 점을 적어 줘. 안 적으면 같은 장면으로 새로 그려", 작게 "이름이나 숫자는 그림에 넣지 않아", 글 칸, "0/200", "2번 더 그릴 수 있어", '다시 그려 줘'(52px) | |
| SCR-115#sending | 버튼이 꺼지고 "보내는 중…". 202가 오면 칸이 닫히고 한 날이 SCR-113#redrawing | API-112#202 |
| SCR-115#input-error | 글 칸 아래 "200자까지 쓸 수 있어" 또는 "뭔가 잘못 보냈나 봐. 다시 해 볼게", 쓴 말 그대로 | API-112#400 |
| SCR-115#limited | 버튼이 꺼지고 이유 한 줄: `drawing_budget` "이번 달 그림을 다 그렸어. 다음 달에 또 그려 줄게", `redraw_limit` "그림은 두 번 다 다시 그렸어", `too_many_requests` "너무 빨라! 조금 있다가 해 줘"와 남은 초(그 뒤 다시 켜짐) | API-112#429, API-112#409(`redraw_limit`) |
| SCR-115#stale | `stale_revision` → 한 날을 다시 불러오고 칸은 연 채 "그 사이 일기가 바뀌었어. 새로 보여 줄게". `busy` → 칸을 닫고 SCR-113#fixing·#redrawing. `not_ready` → 칸을 닫고 한 날이 그 상태 | API-112#409(`stale_revision`·`busy`·`not_ready`) |
| SCR-115#permission | 401 → 쓴 말을 남기고 새로 불러 Access 로그인, 돌아오면 칸을 다시 엶. 403 `not_allowed`·`no_dm` → SCR-113#permission. 403 `cross_site` → "이 화면에서 다시 해 줘" | API-112#401, API-112#403 |
| SCR-115#error | 쓴 말 그대로, "잠깐 문제가 생겼어. 조금 있다가 다시 해 줘"(`db_unavailable`) 또는 "잠깐 문제가 생겼어. 다시 해 볼래?"와 추적 id, '다시 보내기' | API-112#503, API-112#default, 네트워크 없음·시간 넘김 |

- 결과는 이 칸이 아니라 한 날에 보여요: 새 그림(SCR-113#redrawn), 못 그림(#redraw-failed), 그릴 수 없는 말(#scene-rejected, '다시 적기'로 이 칸이 쓴 말 그대로 다시 열림).
- 멱등 키는 SCR-114와 같은 규칙이에요.
- loading·empty: 한 날이 불러 둔 값을 써요. 빈 칸이 처음 모습이고, 비운 채 보내도 돼요.
- 경우의 종류: 접근(#permission), 입력(#input-error), 상태 변화(#stale), 반복(버튼 꺼짐, 멱등 키), 동시(`busy`), 한도(#limited, 남은 수), 바깥 서비스(그림 실패는 한 날의 #redraw-failed), 데이터 노출(바꿀 점과 장면은 응답·로그에 없음), 끊긴 흐름(202 뒤 화면을 닫아도 다음에 열면 한 날이 결과를 보임), AI 답(그릴 수 없는 말은 #scene-rejected의 정해진 말).
