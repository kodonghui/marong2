# SCR-116 한 달 달력

Purpose: 한 달의 일기를 마음 날씨와 도장으로 한눈에 보고, 날을 골라 여는 칸이에요. (FL-117)

주소: `/chat/diary/:date#calendar`. 한 날 위에 화면 가득 열려요. 처음에는 그 날의 달이에요.

목업(09단계, A 그림일기장): 디자인 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)의 'A · SCR-116#…' 대지 5장이에요. #normal은 `A-calendar-night-360.dc.html`, 나머지는 `A116-<상태>.dc.html`(360px)이에요. #permission은 칸을 닫고 SCR-113#permission을 보여서 따로 그리지 않았어요. 다르면 이 정의가 맞아요.

- 날씨는 그림과 글자 이름을 같이 둬요(색만으로 구별하지 않음). 360px에서 한 칸은 약 46px이라 날씨 그림 24px과 날짜 숫자가 들어가요.
- stale: 열 때마다 API-109를 다시 불러요. 한 날에서 날씨를 바꾼 뒤 열면 바뀐 날씨예요.
- 숨긴 날은 달력에 없어서 숨긴 일기는 머리의 ⋯ → 숨긴 일기(SCR-117)로 찾아요.
- 경우의 종류: 접근(#permission), 입력(달은 화면이 만들어서 400은 #error), 빈 답(#empty), 바깥 서비스(#reconnecting, #error), 데이터 노출(날짜·날씨·도장만, 제목·글 없음), 화면 상태(360px·430px).
