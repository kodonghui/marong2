# SCR-117 숨긴 일기

Purpose: 숨긴 일기를 날짜와 제목으로 보고, 열거나 다시 보이게 하는 칸이에요. 숨기기는 지우기가 아니에요. (FL-117)

주소: `/chat/diary/:date#hidden`. 한 날 머리의 ⋯ → 숨긴 일기, 또는 숨긴 뒤 뜨는 말의 링크로 열어요.

목업(09단계, A 그림일기장): 디자인 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)의 'A · SCR-117#…' 대지 6장이에요(`A117-<상태>.dc.html`, 360px). #error는 화면 전체(`A117-error`)와 '다시 보이게'만 실패한 줄(`A117-row-error`) 두 가지예요. #permission의 403은 SCR-113#permission이고, `cross_site`의 한 줄은 `A117-row-error`와 같은 자리에 글만 달라서 따로 그리지 않았어요. 다르면 이 정의가 맞아요.
