# SCR-118 내 모습 카드

Purpose: 그림에 친구가 나올 때 쓸 머리 모양·안경·윗옷 색을 목록에서 고르거나, 카드를 비워 친구가 안 나오게 하는 칸이에요. (FL-119)

주소: `/chat/diary/:date#look`. 한 날 머리의 ⋯ → 내 모습 카드, 또는 일기가 아직 없을 때(SCR-113#empty)의 버튼으로 열어요.

목업(09단계, A 그림일기장): 디자인 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)의 'A · SCR-118#…' 대지 7장이에요(`A118-<상태>.dc.html`, 360px). #normal은 윗옷 색을 바꾼 뒤예요. #permission의 403은 SCR-113#permission이고, `cross_site`의 말은 `A118-error`와 같은 자리에 글만 달라서 따로 그리지 않았어요. 360px에서 안경 고르기는 두 줄로 넘어가요. 다르면 이 정의가 맞아요.

- 칩은 글자 이름으로 보여요. 윗옷 색 칩에는 색 동그라미를 같이 두되 이름이 늘 함께 있어요(색만으로 구별하지 않음).
- 카드 값은 그림 지시문에만 쓰여요. 화면의 미리 보기는 한국어 이름이고 영어 지시문은 보이지 않아요.
- stale: 열 때마다 API-118을 다시 불러요. 저장은 마지막에 저장한 값이 이겨요(판 번호 없음).
- 경우의 종류: 접근(#permission), 입력(목록에서만 고름, 400은 #error), 반복(저장 중 버튼 꺼짐, 같은 값이면 그대로 200, 빈 카드 비우기는 그대로 204), 바깥 서비스(#reconnecting, #error), 데이터 노출(이 친구의 카드만), 화면 상태(윗옷 색 여덟 칩은 360px에서 두 줄).
