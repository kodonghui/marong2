# SCR-119 듣기 시험

Purpose: 현경님이 후보 목소리가 읽은 같은 마롱이 말투 문장을 이름을 모른 채 듣고, 소리마다 자연스러움 1\~5와 문장마다 '마롱이 같다' 하나를 고르는 화면이에요. (FL-123)

주소: `/chat/listen/`. 동희님이 보낸 주소로만 들어와요. 다른 화면에서 가는 길은 없어요.

목업(09단계): 디자인 캔버스 [마롱이의 일기 화면 설계](https://claude.ai/artifact/CC154gunovJS3tqa8XkpZ9)의 'SCR-119#…' 대지 10장이에요(`A119-<상태>.dc.html`, 360px). 듣기 시험은 일기장이 아니라 글 대화와 같은 모양(테마 색, 시스템 글꼴)으로 그렸어요. 상태 9개를 모두 그렸고, #error는 화면 전체(`A119-error`)와 소리 하나만 못 받은 줄(`A119-sound-missing`) 두 가지예요. #permission의 마롱이 얼굴은 이 정의에 번호가 없어서 얼굴 쓰임표([`design/marong-face/README.md`](../../design/marong-face/README.md))의 권한 얼굴(13)로 그렸어요(제안). 다르면 이 정의가 맞아요.

- 소리는 `<audio>`가 상태 번호를 읽지 못해서 실패는 모두 그 줄의 "그 소리를 찾지 못했어"와 시험 다시 불러오기예요.
- 데이터 노출: 후보 이름·모델 이름·정답표는 화면과 응답 어디에도 없어요. 소리 순서는 친구와 문장마다 섞여요(06 결정 3).
- 반복: 점수를 빨리 바꿔 눌러도 마지막 값이 남아요(소리마다 답 하나). 보내는 동안 그 줄만 잠깐 꺼요.
- 360px에서 점수 버튼 다섯 개는 한 줄(버튼 48px)이고, 소리가 여덟 개면 문장 상자 아래로 스크롤해요.
- 경우의 종류: 접근(#permission), 입력(점수는 버튼으로만), 대상(소리 404 → 다시 불러오기), 동시(#stale), 반복(마지막 값), 바깥 서비스(#reconnecting, #error), 데이터 노출(위), 빈 답(#empty), 화면 상태(360px·430px).
