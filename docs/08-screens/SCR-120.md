# SCR-120 친구 약속

Purpose: 친구가 '나는 이런 친구가 필요해'(친구 약속)와 꼭 지킬 것(친구 규칙)을 한 화면에서 보고 바꾸는 곳이에요. 첫 질문을 글 대화 대신 여기서 끝낼 수도 있어요. (FL-124, FL-125, FL-126, FL-127)

주소: `/chat/persona/`. 글 대화(SCR-107) 머리의 '나' 버튼, 약속 초안 카드의 '고칠래'(SCR-123, `effect: open_card_screen`이면 `/chat/persona/?from=draft`)로 열어요. `from=draft`는 화면 안에서만 읽고 서버로 보내지 않아요. 머리 왼쪽 '글 대화'는 `/chat/`로 가요.

목업(09단계): 후보 A·B는 [`design/persona-candidates.md`](../../design/persona-candidates.md). 방향을 정하면 이 줄에 대지 이름을 적어요. 다르면 이 정의가 맞아요.

| Data | Source |
| --- | --- |
| 약속 상태(`state`), 세 값(`support`·`advice`·`honesty`)과 대화 이끌기(`lead`), 선톡 정도, 먼저 전화, 약속 문장, 정한 때와 정한 곳(`setAt`, `source`), 지금 바람(`want`), 친구 규칙과 한도 | API-127 |
| 맞춤형 지침 줄: 이해한 내용의 첫 문장(없으면 "아직 없어") | API-131 |

화면 순서(위에서 아래로):

1. 머리: '글 대화', 제목 '친구 약속'.
2. 약속 문장 카드: 작은 글 "마롱이 약속", 문장, 아래 작은 줄 "11월 18일 · 첫 질문으로 정함". 정한 곳 글은 `questions` 첫 질문으로, `draft` 대화를 보고, `draft_silent` 초안 그대로, `default` 기본으로, `proposal` 바꾸기 제안으로, `talk` 대화에서, `screen` 여기서, `admin` 동희가예요. 지금 바람이 있으면 카드 아래 띠 "지금은 '그냥 들어주기'로 할게 · 내일 오전 10시까지"(SPEC-195).
3. 고르기 그룹 네 개: "힘들 때 나한테 제일 바라는 건?"(지지 방식 6칸), "조언은 언제 해 줄까?"(3칸), "내가 좀 아닌 것 같을 때는?"(3칸), "이야기는 누가 이끌까?"(따라갈게, 네가 이끌어 줘). 칸 글은 명세 3.9와 같아요.
4. 선톡: 보통, 적게(하루 1번), 끔. 지금보다 많은 칸은 꺼져 있고 아래 작은 글 "늘리는 건 대화에서 말해 줘. 동희한테 남겨 둘게"(계약 4, SPEC-202).
5. 먼저 전화: "켜져 있어" 또는 "꺼져 있어"(보이기만, 계약 5). 아래 작은 글 "끄려면 '먼저 전화하지 마', 켜려면 '먼저 전화해도 돼'라고 글 대화에서 말해 줘"(call-first 3.7, SPEC-277).
6. 꼭 지킬 것(친구 규칙): 세 그룹 "이렇게 부르지 마"(금지 호칭), "이 얘기는 꺼내지 마"(싫은 주제), "이렇게 불러 줘"(부르는 이름, 하나). 그룹마다 규칙 칩(글 + 지우기 ×, 48px)과 '더하기' 글 버튼. '더하기'는 그 자리에 입력 칸과 '넣기'·'그만'을 열어요. 아래 작은 글 "꼭 지킬 것은 단체방에서도 지켜. 약속은 둘이 얘기할 때만 써"(SPEC-194).
7. 줄 두 개: '맞춤형 지침'(오른쪽에 첫 문장 또는 "아직 없어") → SCR-121, '마롱이가 기억하는 나' → SCR-122.
8. 작은 줄: "여기서 바꾼 건 다음 답부터 디스코드·카톡·앱·통화에 다 적용돼"(SPEC-194).

- empty: #none이 약속의 빈 상태예요. 규칙이 없으면 그룹마다 "아직 없어".
- stale: 페이지가 다시 보일 때 API-127·131을 다시 불러요. 대화에서 "선톡 좀 줄여"라고 한 뒤 돌아오면 그때 '적게'로 보여요. 나중 쓰기가 이겨서 409가 없어요(계약 3).
