# SCR-121 맞춤형 지침

Purpose: 친구가 '마롱이가 이렇게 대해 주면 좋겠어'를 직접 적고, 마롱이가 이해한 내용과 옮긴 것, 못 지키는 것을 바로 확인하는 화면이에요. (FL-128)

주소: `/chat/persona/instructions`. 친구 약속(SCR-120)의 '맞춤형 지침' 줄로 열어요. 머리 왼쪽 '친구 약속'은 `/chat/persona/`로 가요.

목업(09단계): 후보 A·B는 [`design/persona-candidates.md`](../../design/persona-candidates.md). 방향을 정하면 이 줄에 대지 이름을 적어요. 다르면 이 정의가 맞아요.

| Data | Source |
| --- | --- |
| 적은 글, 이해한 내용, 존댓말 여부, 버전, 고친 때 | API-131 |
| 저장 직후의 옮긴 것(친구 규칙, 선톡 줄이기), 동희님께 남겼는지, 못 지키는 한 줄 | API-132 응답(저장하지 않아서 다시 열면 없음) |

화면 순서:

1. 머리: '친구 약속', 제목 '맞춤형 지침'.
2. 안내 글: "말투나 대하는 방식을 편하게 적어 줘. 둘이 얘기할 때랑 통화에만 써".
3. 글 칸(여러 줄, 6줄 높이, 500자까지 `maxlength`), 오른쪽 아래 "120/500". 빈 칸 안내 글 "예: 반말로 짧게 말해 줘. 내가 힘들다고 하면 해결책보다 먼저 들어줘."
4. 주 버튼 '저장'(글이 바뀌었고 앞뒤 빈칸을 뺀 글이 1자 이상일 때만 켜짐), 그 옆이나 아래 글 버튼 '지우기'(적은 지침이 있을 때만).
5. 이해한 내용 카드(마롱이 말풍선 모양, 얼굴 작게): 머리 "이렇게 이해했어", 이해한 내용(3문장 이내), 아래 작은 줄 "11월 18일에 고침".
6. 저장 직후에만 카드 아래 줄들: 옮긴 규칙 "꼭 지킬 것에 넣었어: '야'라고 부르지 않기", 선톡 "선톡을 적게로 바꿨어", 동희님께 남김 "선톡 늘리는 건 동희한테 남겨 뒀어", 못 지키는 것(`cannot`) 그 한 줄. 옮긴 규칙 줄은 SCR-120으로 가는 링크예요.
7. 작은 줄(늘): "위험할 때 하는 말과 사실은 지침으로 바꿀 수 없어"(SPEC-200 머리 줄).

| Action | Result | Failure |
| --- | --- | --- |
| '저장' | API-132(앞뒤 빈칸을 뺀 글) → 이해한 내용 카드가 새 글로 바뀌고 6의 줄들, 알림 조각 "적었어". 이해한 내용 카드가 화면 밖이면 그 카드가 보이게 부드럽게 내려 줘요(D63 ⑥, '움직임 줄이기' 설정이면 바로 이동). 글 칸은 저장한 글 | 400 → 칸 옆 "뭔가 잘못 보냈나 봐. 다시 해 볼게", 글 그대로. 429 → "너무 빨라! 조금 있다가 해 줘", 버튼에 남은 초("12초 뒤에")를 `Retry-After`만큼. 503 `ai_unavailable` → 버튼 위 "지금 잘 못 읽었어, 조금 뒤에 다시 말해 줄래?", 글 그대로, 버튼 다시 켜짐. 503 `db_unavailable` → 띠. `default`·시간 넘김(15초) → 짧은 말과 '다시 해 볼게' |
| '지우기' | 그 자리에 확인 줄 "적은 지침을 지울까? 다음 답부터 빠져"와 '지우기'·'그만'. '지우기' → API-133 → 204, 칸이 비고 카드가 사라짐, 알림 조각 "지웠어" | 503·`default` → 확인 줄 옆 짧은 말, 지침 그대로 |
| 옮긴 규칙 줄 | SCR-120의 꼭 지킬 것 | 없음 |
| '친구 약속' | `/chat/persona/`. 저장 안 한 글이 있으면 이 기기 `sessionStorage`에 남겨 다시 열면 칸에 넣음 | 없음 |

| State | What the user sees and can do | From responses |
| --- | --- | --- |
| SCR-121#loading | 머리, 안내 글, 회색 글 칸과 카드 모양. 버튼 꺼짐 | |
| SCR-121#empty | 한 번도 적지 않음(버전 0). 빈 칸과 안내 글 예시, '저장' 꺼짐, 카드 없음, '지우기' 없음 | API-131#200(`version: 0` 또는 `text: null`), API-133#204 |
| SCR-121#normal | 적은 글이 칸에, 이해한 내용 카드, 고친 때. '저장'은 글을 바꿔야 켜짐 | API-131#200 |
| SCR-121#reading | 저장을 누른 뒤. 칸은 읽기만, 버튼 '읽는 중…'(꺼짐), 카드 자리에 "마롱이가 읽고 있어"와 점 세 개. 길면 10초 넘게 걸릴 수 있어요(AI-14) | |
| SCR-121#saved | #normal에 6의 줄들과 알림 조각 "적었어". 옮긴 것이 없으면 줄 없음 | API-132#200 |
| SCR-121#limited | 1분에 5번을 넘김. 버튼에 남은 초, 글 그대로 | API-132#429 |
| SCR-121#permission | 401 → 쓴 글을 남기고 새로 불러 Access 로그인, 돌아오면 칸에 다시. 403 `not_allowed`·`feature_off` → 안내 화면과 '친구 약속으로'. `cross_site` → 버튼 옆 "이 화면에서 다시 해 줘" | API-131#401·403, API-132#401·403, API-133#401·403 |
| SCR-121#reconnecting | 띠 "잠깐 문제가 생겼어. 조금 있다가 다시 해 줘", 불러오기는 5초부터 늘려 가며 다시. 쓴 글 그대로 | API-131#503, API-132#503(`db_unavailable`), API-133#503 |
| SCR-121#error | 처음 불러오기 실패 → 안내 화면, '다시 해 볼게', 추적 id. 저장의 모델 실패 → 버튼 위 그 말과 글 그대로. 그 밖의 저장·지우기 실패 → 버튼 옆 짧은 말 | API-131#default, API-132#400·503(`ai_unavailable`)·default, API-133#default, 네트워크 없음·시간 넘김 |
| SCR-121#stale | 화면이 다시 보였는데 서버 버전이 바뀜(대화에서 "앞으로 이렇게 대해 줘"). 칸을 안 고쳤으면 새 글로 바꿈. 고치던 중이면 칸은 두고 위에 "대화에서 바뀐 지침이 있어. 저장하면 지금 쓴 글로 바뀌어"와 '바뀐 글 보기' | API-131#200(버전이 다름) |

- 같은 글 다시 저장: '저장'이 꺼져 있어 보내지 않아요. 보내도 서버는 같은 처리예요(모델을 다시 부름).
- 존댓말(`polite`)은 화면에 따로 고르는 칸이 없어요. 글에 "존댓말 써 줘"가 있으면 AI-14가 정하고 이해한 내용에 나와요.
- 경우의 종류: 접근(#permission), 입력(500자는 칸이 막고 400이면 칸 옆), 반복(읽는 동안 버튼 막음), 동시(#stale, 나중 쓰기), 한도(#limited), 바깥 서비스(모델 실패 503, 쓴 글 그대로), 데이터 노출(이해한 내용·옮긴 것만, 모델 이름·근거 없음), AI 답(이해한 내용과 못 지키는 줄은 글로만, 위험할 때 하는 말은 바뀌지 않는다는 줄이 늘 있음), 화면 상태(360px에서 500자 글과 3문장 이해 내용).
