# SCR-122 마롱이가 기억하는 나

Purpose: 마롱이가 친구에 대해 적어 둔 기억과 기다리는 얘기(열린 고리)를 들은 때·곳과 함께 보고, 하나씩 잊어 달라고 하는 화면이에요. (FL-135)

주소: `/chat/persona/memory`. 친구 약속(SCR-120)의 '마롱이가 기억하는 나' 줄로 열어요. 머리 왼쪽 '친구 약속'은 `/chat/persona/`로 가요.

목업(09단계): 후보 A·B는 [`design/persona-candidates.md`](../../design/persona-candidates.md). 방향을 정하면 이 줄에 대지 이름을 적어요. 다르면 이 정의가 맞아요.

| Data | Source |

| 기억 항목(종류, 글, 들은 때, 들은 곳, 인용, 공개 범위, 민감 여부, 유효 기한), 들은 때 새것부터 100개씩 | API-134 (`before`로 다음 100개) |
| 기다리는 얘기(글, 기한, 들은 때, 들은 곳), 기한 가까운 것부터 50개까지 | API-134 첫 쪽 |

화면 순서:

1. 머리: '친구 약속', 제목 '마롱이가 기억하는 나'.
2. 안내 글: "대화에서 들은 걸 이렇게 적어 뒀어. 잊어 달라고 하면 바로 잊을게".
3. 기다리는 얘기: 줄마다 글, 작은 줄 "11월 20일까지 · 11월 17일 디스코드 DM", 오른쪽 '잊기'. 없으면 이 그룹을 보이지 않아요.
4. 기억 그룹 다섯 개(종류별, SPEC-234): 사실, 좋아하는 것(`preference`), 일·계획(`event`), 사람(`relation`), 힘든 일(`hard`). 항목이 없는 그룹은 보이지 않아요. 그룹 안은 들은 때 새것부터예요.
5. 기억 줄: 글(80자까지, 감김), 작은 줄 "11월 2일 · 디스코드 DM"(유효 기한이 있으면 "· 11월 30일까지"), 표시 "둘만 아는 얘기"(민감, 1:1에서만 씀)와 "단체방에서만"(`scope: group`), 오른쪽 '잊기'. 인용이 있으면 '들은 말 보기' 글 버튼이 그 자리에서 “들은 말”(120자까지)을 열고 닫아요.
6. 100개가 넘으면 맨 아래 '더 보기'.
7. 들은 곳 글: `discord_dm` 디스코드 DM, `app` 앱, `kakao_dm` 카톡, `kakao_group` 카톡 단체방, `discord_server` 디스코드 서버, `call` 통화. 방 이름은 응답에 없어서 보이지 않아요.

| Action | Result | Failure |
| --- | --- | --- |
| '잊기' | 그 줄 아래에 확인 줄 "이걸 잊을까? 같은 말에서 나온 기억도 같이 잊어"와 '잊기'·'그만'. 확인 '잊기' → 새 멱등 키로 API-135 → 200, 같은 근거에서 나온 줄들이 빠지고 알림 조각 "잊었어 · 기억 2개, 들은 말 1개"(`forgot`, `messages`). 같은 근거의 다른 줄이 화면에 남을 수 있어서 목록을 다시 불러요 | 404 → "찾지 못했어. 새로 보여 줄게"와 목록 다시. 503 → 확인 줄 옆 "잠깐 문제가 생겼어. 조금 있다가 다시 해 줘", 확인 줄 그대로. 답 없이 끊김(네트워크·시간 넘김) → 확인 줄 옆 '다시 해 볼게'가 같은 멱등 키로 다시 보냄. 400 → 짧은 말과 목록 다시 |
| '그만' | 확인 줄이 닫힘 | 없음 |
| '들은 말 보기' | 인용을 열고 닫음(서버로 가지 않음) | 없음 |
| '더 보기' | API-134(`before`=지금 마지막 항목 id) → 아래에 이어 붙임(같은 그룹 안에 들은 때 순서로) | 아래 #error와 같고 이미 보인 줄은 그대로 |
| '친구 약속' | `/chat/persona/` | 없음 |

- stale: 화면이 다시 보일 때 첫 쪽을 다시 불러요. 대화에서 "그거 잊어줘"로 잊은 기억은 그때 빠져요. 잊은 뒤에는 늘 다시 불러요.
- 잊은 기억은 되살리지 않아요(글을 비움, TBL-123). 확인 줄이 그 말을 미리 알려요.
- 경우의 종류: 접근(#permission, 남의 항목 id는 404), 대상(이미 잊은 항목 404 → 다시 불러옴), 반복(같은 멱등 키는 처음 결과, 잊는 동안 막음), 바깥 서비스(503 띠), 데이터 노출(방 이름·근거 메시지 id·민감 종류 없음, 본인 화면이라 인용은 보임), 빈 답(#empty), 화면 상태(360px에서 80자 글, 120자 인용, 표시 두 개가 한 줄을 넘음 → 감김).
