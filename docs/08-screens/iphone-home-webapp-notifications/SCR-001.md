# SCR-001 통화 홈 · 알림으로 확인한 전화

08단계 초안 · FL-225·226·227 · SPEC-539·540·542·545~552

현재 계정의 약속 전화가 확인된 사용자에게 최신 결과와 별도 받기 또는 만료 뒤 일반 통화 선택을 제공합니다.

[변경 상태 와이어프레임](../wireframes-iphone-home-webapp-notifications.draft.html#scr-001) · [응답 대조표](README.md#api-응답-대조표)

## 데이터

| 표시하거나 처리하는 값 | 출처와 표시 범위 |
| --- | --- |
| 이 계정의 확인된 전화 상태와 응답 기한 | API-314#200의 전화 상태, `ring_ready.answerUntil`만 필요할 때 안내에 사용합니다. 별도의 일정 제목·할 말·사용자 식별값을 이 응답에서 추측해 표시하지 않습니다. |
| 받기 수락·기존 결과 | API-315#200 `accepted.callId`·`connectToken`은 확인된 통화의 내부 연결 자료입니다. 화면에 원본 값을 표시하지 않습니다. |
| 일반 통화 여부와 재연결 결과 | API-317의 시작 모드, `ready.ring`과 동일 통화 조건. 기존 통화 홈 상태와 제한은 API-124·107의 기존 정의를 사용합니다. |

## 행동과 결과

| 행동 | 결과 | 실패·취소 |
| --- | --- | --- |
| ‘받기’ 선택 | 선택한 뒤에만 현재 마이크 준비를 확인하고 API-315로 최초 수락을 요청합니다. 같은 클라이언트에서 확인된 결과로만 SCR-002로 이어갑니다. | 미수락 만료 → #notice-ring-expired. 다른 기기 선행 수락 → #notice-ring-answered. 마이크 거절 전에는 수락을 보내지 않고 기존 SCR-002#mic-denied를 사용합니다. |
| ‘결과 확인’ 선택 | 아직 같은 유효 클라이언트에 보존된 처음 받기의 대상과 요청을 API-315로 확인합니다. 이미 성공했던 경우 같은 통화만 이어집니다. | 응답이 또 불확실하면 결과 미확인에 남습니다. 단기 요청이 사라지거나 재로그인한 경우 API-314 조회로 돌아가고, 받은 것으로 추정하거나 수락을 자동 제출하지 않습니다. |
| 미수락 만료에서 ‘일반 통화’ 선택 | 다시 확인한 만료 대상에서만 API-317 `start_ordinary`로 시작합니다. 기존 일반 통화 조건을 따릅니다. | 취소·권한 실패·연결 실패에는 일반 통화를 자동 실행하지 않습니다. 다른 약속 전화까지 받아서는 안 됩니다. |
| 복구가 불가한 통화에서 ‘다시 걸기’ | 기존 일반 통화 흐름을 사용합니다. 이 조작은 만료된 알림의 전용 모드와 다른 기존 발신입니다. | 기존 마이크·서버 제한 또는 실패 상태를 사용합니다. |
| 글 대화로 돌아가기 | 보류한 참조와 요청을 정리하고 기존 안전한 SCR-107 진입으로 돌아갑니다. | 현재 세션이 종료됐으면 기존 로그인만 안내합니다. |

## 화면 규칙

- 확인된 전화만 SCR-001의 전화 상태에 들어옵니다. 잠금 해제 또는 재로그인 도중 미수락 만료와 받기 직전 미수락 만료는 같은 만료 상태로 표시합니다. 이미 유효하게 수락한 전화는 기한이 지나도 ‘이미 수락’으로 우선 판정합니다.
- API-315의 409 `call_busy`·`calls_full`·`budget_exhausted`와 429 `daily_limit`은 기존 SCR-001#call-busy·#calls-full·#budget·#daily-limit을 사용합니다. 401은 SCR-164#notice-login에 연결합니다. 권한 없는 요청에는 위 기존 상태로 타인의 전화 정보를 표시하지 않습니다.
- 분리된 SCR-001·002의 전환은 기존 화면의 논리적 변화입니다. SCR-001의 설계 주소 `/` 및 SCR-002의 설계 주소 `/call`로 알림을 강제 이동시키거나 새 HTTP 페이지로 취급하지 않습니다. 기존 웹앱 창·클라이언트 맥락에서 06의 진입과 시작 계약으로 동작합니다.
- 통화 홈의 기본·마이크·기본 실패·일반 Safari 직접 통화는 원본을 참조합니다. 이 알림 진입에서 필요한 빈 상태는 없습니다. 대상이 없거나 유효하지 않으면 안전한 접근 불가입니다.
