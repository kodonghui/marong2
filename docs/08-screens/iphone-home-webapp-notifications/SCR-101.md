# SCR-101 Android 통화 화면 · 기존 상태 재사용

08단계 초안 · FL-228·225 · SPEC-546·549·553

Android 사용자는 기존 약속 전화 화면을 사용하며, 다른 클라이언트가 같은 전화를 먼저 받았을 때 기존 통화 중 안내를 확인합니다.

## 데이터

| 표시하거나 처리하는 값 | 출처와 표시 범위 |
| --- | --- |
| 기존 응답 | API-107 기존 `call_busy` 프레임. 새로운 Android 응답 구조는 없습니다. |

## 행동과 결과

| 행동 | 결과 | 실패·취소 |
| --- | --- | --- |
| 기존 벨에서 수락 | 같은 약속 전화를 다른 클라이언트가 먼저 유효하게 수락한 경우 기존 `call_busy` 안내를 사용합니다. | 해당 기존 통화에는 중복 연결이나 종료 요청을 보내지 않습니다. 일반·미수락 만료·직접 통화의 나머지 결과는 기존 정의를 따릅니다. |

## 기존 상태

기존 `SCR-001#call-busy`와 정상·오류 상태를 재사용합니다.

## 화면 규칙

- 이번 항목은 06 Q3의 응답 적용 조건만 다룹니다. 화면 문구·모양·초점 순서는 기존 SCR-101 및 SCR-001#call-busy를 재사용하므로 새 프레임이 없습니다. 양쪽 선착순 수락 한 건과 첫 양방향 연결 한 건은 기기에서 확인합니다.
