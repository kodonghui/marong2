# SCR-109 글 대화 메뉴 · 문구 변경 검토

08단계 초안 · FL-220·227 · SPEC-520·552

기존 글 대화 메뉴에서 일반 Safari와 설치한 웹앱을 혼동시키지 않는 안내를 검토합니다.

## 데이터

| 표시하거나 처리하는 값 | 출처와 표시 범위 |
| --- | --- |
| 안내의 적용 범위 | 클라이언트 실행 형태. 실제 구독의 조회·변경은 SCR-165에서만 다룹니다. |

## 행동과 결과

| 행동 | 결과 | 실패·취소 |
| --- | --- | --- |
| 기존 ‘내 마롱이’ 열기 | 기존 SCR-165로 갑니다. | 기존 로그인·글 대화 메뉴 상태로 돌아갑니다. |

## 변경 상태

화면 글은 검토용 문구입니다.

| 상태 | 분류 | 제목 | 표시 | 조작 | 초점 및 읽기 | 응답·조건 |
| --- | --- | --- | --- | --- | --- | --- |
| <a id="ios-menu-copy"></a>`SCR-109#ios-menu-copy` | normal | 알림 안내 | 아이폰에서는 홈 화면에 추가한 뒤 내 마롱이에서 이 기기의 알림을 확인할 수 있어. | 내 마롱이 | 기존 메뉴의 초점 순서에서 ‘내 마롱이’를 유지합니다. | 별도 승인 후보. API 추가 없음 |

## 화면 규칙

- 07에서는 메뉴를 재사용했습니다. 현재 문구의 플랫폼 안내만 바꾸는 제안은 [별도 승인 후보](../../../iphone-webapp-08-screen-checkpoint-2026-11-25.md#별도-승인-후보)입니다. 메뉴 경로, 조작, Android 업데이트와 알림 메뉴는 기존 정의를 사용합니다.
