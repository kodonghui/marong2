# SCR-164 로그인 · 알림에서 복귀

08단계 초안 · FL-220·221·223·225·227 · SPEC-528·530·539·540·542·546·547·552

알림 탭 또는 설정·받기 도중 로그인 종료를 만난 사용자가 기존 인증을 마치고 현재 대상이나 설치 상태를 다시 확인합니다.

[기존 로그인 폼·기기 코드 오류](../unified.md#scr-164-로그인)

[변경 상태 와이어프레임](../wireframes-iphone-home-webapp-notifications.draft.html#scr-164) · [응답 대조표](README.md#api-응답-대조표)

## 데이터

| 표시하거나 처리하는 값 | 출처와 표시 범위 |
| --- | --- |
| 기존 로그인 응답 | API-213, 기존 기기 코드 입력과 로그인 응답만 사용합니다. |
| 돌아갈 맥락 | 알림 대상 참조 또는 알림 설정으로 돌아갈 의도를 현재 탐색의 단기 상태로 보존합니다. 화면·URL 쿼리·로그에 대상 내용이 없습니다. |

## 행동과 결과

| 행동 | 결과 | 실패·취소 |
| --- | --- | --- |
| 기존 기기 코드로 로그인 | 성공 또는 이미 로그인됨을 확인하면 SCR-107#notice-loading 또는 SCR-165#notify-loading으로 돌아가 현재 계정·설치에서 재검증합니다. | 정상 오류는 기존 SCR-164의 잘못된 코드·입력·제한·오류 상태를 사용합니다. 실패·취소에서 대상이나 전화 상태를 보여 주지 않습니다. |
| 로그인 취소·뒤로 | 기존 안전한 진입으로 돌아갑니다. 보류한 받기 실행은 폐기합니다. | 로그인 맥락이 유실돼도 자동으로 이전 계정을 복구하거나 호출하지 않습니다. |

화면 글은 검토용 문구입니다.

| 상태 | 분류 | 제목 | 표시 | 조작 | 초점 및 읽기 | 응답·조건 |

## 화면 규칙

- 기기 코드 마스킹·오류·도움·제한은 기존 SCR-164 정의의 상태를 사용합니다. 단기 상태가 소실되면 식별값 없는 기존 글 대화 또는 설정 진입으로 복귀합니다. 다시 로그인했다는 사실만으로 이전 받기·등록을 실행하지 않습니다.
