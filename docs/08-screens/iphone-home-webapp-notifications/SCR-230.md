# SCR-230 홈 화면 웹앱 알림 · iOS 시스템 표면

08단계 초안 · FL-222·223·224·225 · SPEC-532~538·543~545

이 기기가 받은 일반 유형의 알림을 iOS가 표시하고, 사용자가 내용을 열기 전에 앱에서 현재 계정과 대상을 확인할 수 있게 합니다.

## 데이터

| 표시하거나 처리하는 값 | 출처와 표시 범위 |
| --- | --- |
| 제품명·일반 유형 안내 | 06 웹 푸시 페이로드. 새 답변·선톡·일정·약속 전화 유형만 구분하고 방·발신자·일정·전화의 제목과 원문은 제외합니다. |
| 사용자가 누를 주소 | 같은 출처의 `/chat/#notice` 참조는 보호된 진입에만 사용합니다. 사용자 화면에 참조 값을 표시하지 않습니다. |

## 행동과 결과

| 행동 | 결과 | 실패·취소 |
| --- | --- | --- |
| iOS 알림 탭 | 필요하면 OS 잠금을 푼 뒤 SCR-107에서 API-314로 대상 확인만 합니다. | 잠금 취소에 앱 동작이 없습니다. 로그아웃·다른 계정·기한 상태는 현재 앱을 연 뒤 판정합니다. |
| 닫기 또는 그대로 두기 | OS의 기존 표시·닫기 동작을 사용합니다. | 앱 통화 수락·마이크·일반 통화 실행이 없습니다. 동일 이벤트 재도착의 단일 표시는 실기기에서 검증합니다. |

## 화면 규칙

- 와이어프레임은 iOS 디자인을 재현하지 않고 시스템 영역과 제품이 제공하는 일반 유형만 나타냅니다. 잠금 상태에서 시스템 환경에 따라 미리보기가 더 제한될 수 있습니다. 앱이 잠금을 제어하지 않습니다.
- 사용자가 볼 수 없는 서버 송신 중·전송 실패·TTL·억제·중복 상태는 이 표면의 새 화면이 없습니다. 현재 권한 확인과 구독 관리는 SCR-165에 따로 표시합니다. 실제 화면 표시와 잠금·OS 권한 흐름은 실기기에서 확인합니다.
