```markdown
- 겹치는 파일: 다른 패키지와 같이 고치는 파일과 합치는 순서

- 끝 조건: 모든 TASK의 끝 조건 시험 통과, 그리고 이 패키지에만 있는 조건
- 설계 질문: PR 설명 맨 위 '설계 질문'에 적으면 설계 스레드가 답함
```

TASK 표는 corthex 10단계 형식 그대로 쓰고, Owner는 `GPT`(서명처럼 동희님 노트북에서 하는 일도 GPT가 알아서 해요, D65), 끝 조건에는 돌릴 시험 파일이나 명령을 적어요. API를 건드리는 TASK는 그 operation이 나열한 응답마다 시험이 통과해야 끝이에요.
