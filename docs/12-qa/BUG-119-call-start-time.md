# BUG-119 통화 시작 한국 시각이 지시문에서 누락

- 상태 `open` · 심각도 S3 · 우선순위 P2 · 유형 구현 · 원인 11단계
- 발견 운영, 2026-11-24 KST. 기준 SPEC-004. 승인 명세 변경 없음.

## 재현과 회귀 기준

TC-646. UTC 날짜가 한국에서 다음 날로 넘어가는 시각에 가짜 Live 연결을 연다. 기존 요청의 지시문 어디에도 한국 날짜·요일·시각이 없다. ‘통화 시작 시각(한국 시각)’ 한 줄을 확인하고 같은 통화의 재연결과 구간 교체에서도 시작 시각이 유지되는지 확인한다.

기존 지시문 시험은 원본 문구와 기억·도구 지시를 비교했으며 시작 시각과 날짜 경계를 검사하지 않았다.
