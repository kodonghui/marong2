# BUG-120 앱의 인사 지시가 사용자 자막에 저장

- 상태 `open` · 심각도 S3 · 우선순위 P1 · 유형 구현 · 원인 11단계
- 발견 운영, 2026-11-24 KST. 기준 SPEC-017, TASK-460~465의 인사 대기 동작. 승인 명세 변경 없음.

## 재현과 회귀 기준

TC-647. 앱이 연결 직후 보내는 인사 지시를 대기 기능이 없는 연결에 전달한다. 기존 코드는 일반 입력과 같이 사용자 자막과 끊기 동의 판정에 넘긴다. 대기 기능 유무와 관계없이 Live 연결로 인사는 한 번 전달되고, 지시가 사용자 자막이나 채팅 입력으로 저장되지 않는지 확인한다. 정상 텍스트는 계속 자막에 저장된다.

인사 대기 시험은 오디오 준비와 중복 전송을 검사했으며, 대기 기능이 꺼진 경로의 자막 저장을 검사하지 않았다. 운영의 해당 계정에서 오염된 활성 카드 두 개를 읽기로 확인했다. 기존 두 카드의 숨김은 별도 데이터 변경이며 승인 뒤 실행한다.

수정 전 `a39fef4`에서 대기 기능을 쓰지 않은 연결의 인사 지시가 사용자 자막으로 남았다. `7fe94a4`의 `test_call_memory_regressions.py`는 대기 기능을 켜거나 끈 연결 모두 인사 1회 전송, 인사 지시 자막 0건, 정상 텍스트 자막 1건을 확인했다.
