# BUG-128 · 관리 화면에서 통계 스크립트 CSP 차단 콘솔 오류

- 상태: open · 심각도 S3 · 우선순위 P3 · 유형: 운영 설정 · 원인 단계: 미확인
- 발견: 2026-11-27 운영 읽기 전용 화면 걷기, TC-639 · SCR-169·200~204·186·220
- 재현: 관리자 인증 뒤 `/chat/admin/` 아래 화면을 열어 브라우저 콘솔을 확인해요.
- 기대: 화면을 열 때 콘솔 오류가 없어요.
- 실제: Cloudflare 통계 스크립트 `beacon.min.js` 요청이 `script-src` 콘텐츠 보안 정책에 차단돼 콘솔 오류가 나요. 헤드리스 Chromium과 WebKit에서 일곱 화면 모두 재현했어요. 아이템 API의 404는 꺼진 꾸미기에 대해 예상한 응답이며 별도예요.
- 영향: 점검한 화면과 주요 읽기 API의 불러오기 실패는 없었어요. 통계 수집의 실제 영향과 CSP 또는 삽입 설정의 소유 지점은 확인하지 않았어요.
- 증거: 서울 Playwright에서 360·390·430·1280px, 운영 화면 200과 주요 읽기 API 상태 확인. 개인정보를 가린 캡처는 작업공간에만 보관해요.
- 놓친 이유: 이전 반영 확인은 인증 세션 부재로 브라우저 콘솔까지 확인하지 못했어요. 수정과 수정 후 재시험은 아직 하지 않았어요.
