- 환경: 2026-11-27 서울 격리 Chromium, 합성 API, 기준 `8b5f37c`.
- 재현: 사용자 글꼴이 적용된 견본에서 다른 글꼴을 고르고 글꼴 응답을 지연하거나 404로 줘요.

- 원인 단계 11: 승인 문서는 맞고 구현이 달라요. 문서 변경은 없어요.
- 회귀: `apps/android/test/pet-decor.e2e.cjs`의 느린 응답·404 시험이 `8b5f37c`에서 실패했어요.
- 탈출: 기존 TC-551 실행은 느린 글꼴과 404를 실행하지 않았어요. 해당 조건을 회귀 시험에 추가했어요.
