- 관련: TC-546, SPEC-418, SPEC-419, SCR-181#gone, SCR-182#default-marong, SCR-183#default-marong·#diary.
- 환경: 2026-11-27 서울 격리 Chromium, 합성 응답, `fbe6035`.
- 재현: 상점 받기에 404를 주거나 기본 마롱이로 아이템 상세·보관함을 열어요.
- 기대: 내린 카드는 사라지고 정해진 안내가 보여요. 기본 마롱이에 정해진 안내·캐릭터 만들기 링크가 있고 일기장 탭의 선택 품목에는 '쓰는 중'이 보여요.
- 실제: 내린 카드가 남고 다른 오류가 보이며 기본 마롱이의 안내·링크와 선택 표시가 달라요.
- 원인 단계 11: 승인 문서는 맞고 코드가 달라요. 문서 변경은 없어요.
- 회귀: `apps/android/test/pet-decor.e2e.cjs`의 두 TC-546 상태 시험이 `fbe6035`에서 실패했어요.
- 탈출: 기존 TC-546은 정상 받기와 착용 경로만 확인했어요. 각 화면 상태를 별도 시험해요.
- 추가 재현: 상점의 세 칸 카드가 한 열로만 나타났어요. 세 칸과 화면 넘침을 확인하는 회귀가 `fbe6035` 기준에서 실패한 뒤 수정했어요.
- 추가 재현: 보관함에서 받은 배경을 골라도 일기장 꾸미기로 이동해 선택할 수 없었어요. 배경·속지·글꼴의 선택 회귀를 먼저 실패시킨 뒤 고쳤어요.
- 추가 재현: 상점 목록의 500 오류에서 정해진 다시 시도 버튼이 없었어요. 실패 회귀를 추가한 뒤 다시 불러오기와 복구를 고쳤어요.
- 추가 재현: 일기장 꾸밈 아이템 상세에서 견본이 보이지 않았어요. 배경 미리 보기 실패 회귀 뒤 배경·속지·글꼴·스티커 견본을 추가했어요.
- 추가 재현: 상점과 보관함을 불러오는 동안 승인된 회색 자리가 없었어요. 지연 응답 실패 회귀 뒤 자리를 추가했어요.
- 추가 재현: 보관함 저장 중 누른 아이템에 도는 표시가 없었어요. 지연·동시 선택 실패 회귀 뒤 표시와 순차 요청을 확인했어요.
- 추가 재현: 상점 받기의 cross_site 403에서 승인된 안내가 빠졌어요. 403 실패 회귀 뒤 정해진 문구를 표시해요.
