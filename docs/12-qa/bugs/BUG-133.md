- 관련: TC-546, SPEC-420, SCR-183#error, 통합 앱 공통 오류 규칙.
- 환경: 2026-11-27 서울 격리 Chromium, 합성 API 응답.
- 재현: 보관함에서 착용할 때 API-255에 400·404·500을, 상점 받기와 상세 착용에 API-253·255 500을 돌려줘요.
- 기대: 400은 공통 확인 안내, 404는 '찾지 못했어'와 내 마롱이 이동을 보여요. 500은 이전 모습으로 되돌리고 다시 시도할 수 있어요.
- 실제: 404에 다른 아이템 안내가 보이고 쓰기 500에 다시 시도 단추가 없어요.
- 원인 단계 11: 공통 오류 상태가 보관함 착용에 빠졌어요.
- 회귀: `apps/android/test/pet-decor.e2e.cjs`의 400·404와 세 쓰기 500 검사가 각각 수정 전에 실패했어요.
- 탈출: 앞선 화면 시험은 409와 403을 확인하고 404·500 응답을 실행하지 않았어요.
