- 관련: TC-551, REQ-544, SPEC-423, SCR-113.
- 환경: 2026-11-27 서울 격리 Chromium, 합성 일기, 꾸미기 전 main `c5c8918`과 수정 전 `cb45671`.
- 재현: 두 버전의 같은 일기 화면 전체를 찍어 픽셀 비교해요.
- 기대: 꾸미기가 꺼진 화면은 꾸미기 전 main과 같아요. 처음 꾸밈을 저장한 화면도 승인된 신규 스티커·꾸미기 단추와 저장 완료 띠를 제외한 기존 영역이 같아요.
- 실제: 일기 카드 그림자가 다른 요소와 겹치는 순서가 바뀌어 전체 화면 픽셀이 달라요.
- 원인 단계 11: 스티커 유무와 무관하게 일기 카드에 `position: relative`를 지정했어요.
- 회귀: `apps/android/test/pet-decor.e2e.cjs`의 고정된 이전 main과 현재 화면 전체 비교가 수정 전 실패하고 스티커가 있을 때만 위치 기준을 적용한 뒤 통과했어요.
- 탈출: 이전 TC-551 시험은 수정 전 main을 시험 파일에 고정하지 않았고 카드 바깥 그림자는 비교하지 않았어요.
