- 관련: D189, TC-546·553, SCR-185.
- 재현: 오늘 일기로 스티커를 선택해 진입할 때 꾸밈 조회가 500 또는 네트워크 오류를 반환한 뒤 정상화하고 재시도를 눌러요.
- 기대: 꾸밈을 다시 조회하고 해당 스티커가 선택된 편집 화면이 열려요. 꾸미기 꺼짐의 404는 재시도 오류와 구분해요.
- 실제: 최초 실패를 꺼짐 상태로 저장해 재시도해도 조회하지 않고 편집기가 열리지 않아요.
- 원인 단계 11: 일시 오류와 꺼짐을 모두 `null`로 저장했어요.
- 회귀: `apps/android/test/pet-decor.e2e.cjs`의 500·네트워크·꺼짐 404 세 시험이 수정 전 `20614db`에서 실패하고 수정 뒤 통과했어요.
- 탈출: 기존 오류 시험은 스티커 목록 오류를 다뤘으나 최초 꾸밈 조회 실패 뒤 재시도는 다루지 않았어요.
