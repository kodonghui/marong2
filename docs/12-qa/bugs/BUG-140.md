# BUG-140 화면과 그림의 기본 마롱이 차림 불일치

2026-11-28 PR #148 재리뷰에서 발견했어요. 서울 격리 환경에서 유효한 아이템을 입힌 뒤 기본 마롱이 레이어를 지우거나 자리 밖으로 바꾸면 프로필에서는 벗은 것으로 나오지만 일기 지시와 대기 중 반응 그림에는 해당 옷이 남아요. SPEC-572·574와 D196 기준으로 무효 레이어는 기본 마롱이의 유효한 차림이 아니에요. 원인은 11단계에서 프로필 조회만 유효성을 검사하고 일기·반응은 저장된 ID를 그대로 사용한 것이며 승인 문서 변경은 없어요.

회귀 시험: `tests/test_scene_picture.py`의 `test_bug140_` 시험은 유효한 착용 뒤 레이어가 사라지거나 무효가 되는 경우 프로필, 일기 지시, 대기 반응과 이미 생성된 그림 작업을 비교해요. 수정 전 `3765651`에서 실패하고 수정 뒤 결과는 아래 기록해요. 병합 전이므로 상태는 `open`이에요.
