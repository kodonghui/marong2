# BUG-141 그림 작업 중 레이어가 복구되거나 바뀌면 차림이 어긋남

2026-11-28 PR #148 네 번째 리뷰에서 발견했어요. 서울 격리 환경에서 모자와 옷이 유효할 때 옷 반응 그림을 대기시킨 다음 모자를 빼고 그림을 시작해 모자 없이 그리게 해요. 완료 확인 전 모자 파일을 복구하면 처음 대기시킨 차림과 현재 차림이 같아 실제 그림이 틀렸는데도 그대로 반환돼요. 같은 아이템 파일이 유효한 다른 그림으로 바뀌는 경우도 식별자만 비교하면 놓쳐요. SPEC-572·574와 D196에 맞는 실제 유효 차림을 비교해야 하며 원인은 11단계 구현이므로 승인 문서 변경은 없어요.

회귀 시험: `tests/test_scene_picture.py`의 `test_bug141_`은 무효에서 복구와 유효한 파일 내용 변경을 가짜 모델과 임시 DB로 확인해요. 병합 전이므로 상태는 `open`이에요.
