# BUG-143 스위치 0의 기존 그림 동작 보존

2026-11-28 PR #148 여섯 번째 리뷰에서 발견했어요. 기존 완료 장면에 해시 기록이 없거나 받은 옷을 상점에서 내리면 기본 차림 스위치 0에서도 반려동물 반응과 일기 그림을 거절해 기존 동작 및 비용이 달라져요. D193과 SPEC-575는 스위치 0의 기존 동작 보존을 요구해요. 마롱이 정정 `msg_ab491592a003`: 해시 기록이 없는 기존 작업·그림은 기존 방식으로 처리하고, 새 고정 차림 검사는 해시 기록이 있는 작업에 적용해요. 스위치 0의 반려동물·일기는 main과 같은 결과·모델 부름 수를 확인해요(작업 재사용 자체는 승인된 TASK-608).

회귀 시험: `tests/test_switch0_main_comparison.py`는 변경 전 main과 이 브랜치를 각각 임시 DB와 가짜 모델로 실행해 완료 그림 재사용·내린 옷 반응·일기 중 내림의 결과와 호출 수를 비교해요. 병합 전이므로 `open`이에요.
