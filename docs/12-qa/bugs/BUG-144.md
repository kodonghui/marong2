# BUG-144 통화 화두의 그림 확인 누락

2026-11-28 PR #148 여섯 번째 리뷰에서 발견했어요. 통화 화두의 대기하지 않는 경로는 완료 상태만 보고 그림 ID를 반환해, 해시 기록이 있는 새 그림의 고정 차림이 무효여도 사용할 수 있어요. 기존 그림은 해시 기록이 없으면 이전 방식대로 사용하고, 기록이 있는 그림은 같은 공통 검사로 확인해야 해요(`msg_ab491592a003`). 원인은 11단계에서 공통 검사 경로를 건너뛴 구현이며 승인된 동작을 바로잡아요.

회귀 시험: `tests/test_scene_picture.py`의 `test_bug144_`는 대기하지 않는 통화 화두에서 고정 아이템 내림·소유 해제·파일 변경과 기존 해시 없는 그림을 검사해요. 병합 전이므로 `open`이에요.
