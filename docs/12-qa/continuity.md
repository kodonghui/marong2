# 대화 이어 주기: 시험 계획(12단계)

상태: 초안(2026-11-24, Claude). 아직 아무 시험도 돌리지 않았어요. 시험을 쓰고 돌리는 쪽은 GPT예요([AGENTS.md](../../AGENTS.md)).
입력: [기능 명세](../04-functional-spec/continuity.md) SPEC-480\~489의 받아들임 조건과 3.9 받아들임 조건 표, 3.11 고르는 규칙, [요구사항](../02-prd/continuity.md) REQ-600\~612, [흐름](../03-user-flow/) FL-210·211, [작업 목록](../10-wbs/continuity.md) TASK-520\~535.
번호: TC-670\~688(이 패키지 범위 670\~699).

## 공통 조건

- 자료는 모두 지어낸 거예요. 친구 이름은 '시험친구 가'·'시험친구 나', 대화는 이 문서의 예처럼 지어낸 문장만 써요. 운영 DB의 대화·자막·친구 대화 원문은 쓰지 않아요(REQ-200).
- 시각은 가짜 시계로 고정해요. 기준 '지금'은 2026-11-24 화 16:00 KST(07:00 UTC)이고, 서버 시계는 UTC로 둬요. 요일: 11/17 화, 11/18 수, 11/20 금, 11/22 일, 11/23 월, 11/24 화.
- 'Runs as'의 뜻: `unit`은 DB 없는 함수 시험, `db`는 `pgserver`에 마이그레이션을 모두 넣은 진짜 Postgres(DB 계정 `marong`과 `marong_call`의 지금 권한 그대로), `api`는 가짜 Gemini·가짜 Anthropic을 붙인 서버 시험, `real`은 진짜 Gemini Live(Vertex)로 돌리는 기억 시험, `ops`는 운영에서 하는 확인(읽기와 확인 통화), `human`은 사람이 듣거나 폰으로 확인.
- `real` 시험은 인계 절이 허락한 한도 안에서만 돌려요(체크포인트 질문 7, 추천 합쳐 180분·5달러). 쓴 분과 비용을 결과에 함께 적어요.
- 로그·결과 기록에는 개수·비율·ms·토큰·구간 설정 이름만 적어요.
