# 마롱이의 일기·통화 비용 시험 계획(12단계, CTX-007, CTX-002·006 바꿈)

2026-11-17 작성(Claude, corthex 0.12.1). 설계 쪽에서 쓴 계획이고, 시험 코드와 실행은 GPT가 해요([10 WBS의 GPT 인계](../10-wbs/diary-call-cost.md#gpt-인계)). 입력: 흐름 FL-114\~123, 기능 명세 [diary.md](../04-functional-spec/diary.md)(SPEC-150\~168)와 [call-cost.md](../04-functional-spec/call-cost.md)(SPEC-169\~183)의 받아들임 조건·4절 경우의 종류·5절 AI 호출, 계약 다섯 개(API-107\~126)의 응답과 오류 코드, 화면 상태 SCR-113\~119·SCR-001#budget.

- 실행 방법: `api`는 `tests/test_app_diary.py`·`tests/test_listen.py`(가짜 Access 서명 키, 지금 `tests/test_app_chat.py`와 같은 방식), `bot`은 `tests/test_diary.py`(pgserver, 가짜 시계, 가짜 모델), `call`은 `tools/vertex_live/test_call_cost.py`·`test_tuning.py`(가짜 구글 연결, 지금 `test_hangup.py`·`test_relay.py`와 같은 방식), `e2e`는 `apps/android/test/diary-page.e2e.cjs`·`listen-page.e2e.cjs`·`call-page.e2e.cjs`(Playwright, 360px·430px, 두 테마), `manual`은 실제 폰과 운영이에요.
- 모델은 모두 가짜예요. 가짜는 정상 JSON, 스키마가 틀린 JSON, 거절, 시간 넘김, 장면 검사에 걸리는 장면을 골라 돌려줘요. 진짜 모델 호출은 TASK-137·303에서만이에요.
- 503·500은 시험에서 일부러 일으켜요(DB 연결을 끊은 가짜, 처리 함수가 예외를 던지는 가짜). 시각은 가짜 시계로 한국 시각 경계(04:00, 04:10, 08:30, 22:00, 달 끝)를 지나가게 해요.
- 시험 데이터는 지어낸 친구와 지어낸 대화만이에요. 실제 친구 대화·이름은 쓰지 않아요.
- 모든 오류 응답은 Problem Details 모양(`type`, `title`, `status`, `code`, `traceId`)과 계약의 `code`를 함께 봐요. 거절된 요청은 데이터가 그대로인지(버전·그림·횟수·AI 기록 수)도 봐요.
- 결과 칸에는 '통과, 어디서, 커밋'처럼 적어요. 아직 아무것도 돌리지 않았어요.
