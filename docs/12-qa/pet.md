입력: [기능 명세](../04-functional-spec/pet.md) SPEC-310\~369의 받아들임 조건과 예외, 3절 규칙, 4절 경우의 종류, 5절 AI-30\~36과 5.8 질문 범위, 7절. 돌리는 법(`Runs as`):

- `auto`: 저장소의 시험 파일(`tests/test_pet_*.py`). 진짜 Postgres는 `pgserver`이고 시험마다 빈 `marong_pet`을 만들어요. 가짜는 OIDC 발급자(시험 키로 서명), 결제 대행과 본인확인 기관(`marong/pet/pg_fake.py`), 모델 AI-30\~36(정해 둔 답, 지연·오류·거절을 고름), 웹 푸시 서비스(받은 요청을 모음), 통화 서버(시험이 내부 API를 직접 부름)예요. 얼굴 찾기는 진짜 YuNet 모델 파일이에요. 시각은 시험 시계로 움직여요.
- `e2e`: Playwright(Chromium, 360·430px)로 화면을 열고 가짜 백엔드 위에서 상태를 만들어 봐요.
- `agent`: 브라우저 에이전트(Aside, 안 되면 ego lite)가 개발 서버에서 흐름을 걸어 보고 되는 것·안 되는 것·인상을 따로 적어요. 출시 전에는 출시 커밋에서 모든 흐름을 걸어요.
- `real-model`: 진짜 모델을 테스트 키로 불러요. 경우마다 3번 돌리고 통과 수를 적어요. PR마다 1만 원 안이고, 돌리기 전에 셈한 값을 PR에 적어요(10 작업 목록 '시험 환경').
- `server`: 반영한 서버에서 읽기 확인. `manual`: 사람이 폰이나 화면에서 봐요.

시험 데이터는 지어낸 이름·대본과 합성 그림, 공개 데이터셋만 써요. 실제 회원이나 친구의 사진·대화는 쓰지 않아요.
