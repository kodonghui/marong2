# TC-639 운영 화면 요소 경계 측정 · 2026-11-27

운영 관리자 인증, GET만 사용. Chromium·WebKit에서 360·390·430px, 높이 900px로 일곱 화면을 측정했어요. CSS로 숨긴 접근성용 머리글은 제외하고 렌더링된 글·단추·표 칸을 셌어요.

각 칸의 순서는 `전체 / scrollWidth 초과 / 화면 가로 밖 / 부모 가로 밖 / 화면 세로 밖 / 부모 세로 밖 / 말줄임 CSS`예요. 화면 세로 밖에는 긴 페이지의 정상 세로 스크롤 영역도 들어가요. 가로 경계 초과는 모두 가로 스크롤이 가능한 탭 메뉴의 글이었어요. 말줄임은 계산된 `text-overflow: ellipsis` 지정 여부예요.

글자를 ㅁ·0으로 치환해 저장한 캡처는 글자 폭 차이로 원본과 줄바꿈이 달라질 수 있어요. DOM 측정은 치환하기 전 원본에서 했고 캡처는 개인정보 때문에 작업공간에만 둬요.
