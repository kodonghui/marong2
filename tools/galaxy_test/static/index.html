시험 순서

  1. 화면 끄고 15분

    전화 걸기 → 마롱이와 얘기를 시작하고 전원 버튼으로 화면을 꺼요. 15분 동안 가끔 말을 걸어 대답이 계속 들리는지 봐요.

  2. 다른 앱에서 15분

    통화 중에 홈으로 나가 카톡 같은 다른 앱을 써요. 15분 동안 가끔 말을 걸어 봐요.

  3. 쉬는 중 말소리 잡기

    '쉬기 시험 시작'을 누르고 화면 켠 채, 화면 끈 채, 다른 앱에서 각각 3분씩 두며 "마롱아"를 세 번씩 말해요. 감지 수가 늘었는지는 돌아와서 위에서 봐요. 깨우기까지 보려면 아래 칸을 켜요.

  4. 스피커폰·이어폰·블루투스

    통화 중에 소리 길을 바꿔 가며 잘 들리는지, 마롱이 목소리가 내 마이크로 다시 들어가 마롱이가 자기 말에 대답하지 않는지 봐요.

  5. 홈 화면 앱

    Chrome 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'. 설치한 아이콘으로 열어 1번과 3번을 5분씩만 다시 해요. 로그인(Access) 뒤 설치는 실제 주소를 만들 때 따로 봐요.

  6. 화면 켜 두기

    통화 중 화면을 만지지 않고 2분 둬서 꺼지지 않는지 봐요. 절전 모드를 켜고 한 번 더, 배터리가 15% 아래일 때도 되면 한 번 더 봐요.

  7. 마롱이 소리 재기

    통화 중 마롱이가 말할 때 '마롱이 소리' 막대가 움직이는지 봐요.
